WebM EBML Elements for SMPTE 2086 HDR Metadata

This article provides a direct overview of how WebM containers store SMPTE 2086 static High Dynamic Range (HDR) metadata using Extensible Binary Meta Language (EBML). In WebM, mastering display color volume data is structured within a specific hierarchy under the video track settings, utilizing the MasteringMetadata container element to define display primaries, white point coordinates, and luminance boundaries.

The Metadata Hierarchy in WebM

WebM relies on the Matroska specification for its EBML schema. SMPTE 2086 metadata resides inside the video track configuration via the following path:

Segment ➔ Tracks ➔ TrackEntry ➔ Video ➔ Colour ➔ MasteringMetadata

The Colour element (EBML ID 0x55B0) contains global color configuration, while the MasteringMetadata element (EBML ID 0x55D0) is the dedicated sub-container for the SMPTE 2086 standard parameters.

Chromaticity Coordinate Elements

SMPTE 2086 specifies the color primaries and white point of the mastering display using CIE 1931 \((x, y)\) chromaticity coordinates. In WebM, these are stored as 32-bit or 64-bit floating-point values between 0.0 and 1.0:

  • PrimaryRChromaticityX (0x55D1): Red primary chromaticity coordinate X.
  • PrimaryRChromaticityY (0x55D2): Red primary chromaticity coordinate Y.
  • PrimaryGChromaticityX (0x55D3): Green primary chromaticity coordinate X.
  • PrimaryGChromaticityY (0x55D4): Green primary chromaticity coordinate Y.
  • PrimaryBChromaticityX (0x55D5): Blue primary chromaticity coordinate X.
  • PrimaryBChromaticityY (0x55D6): Blue primary chromaticity coordinate Y.
  • WhitePointChromaticityX (0x55D7): White point chromaticity coordinate X.
  • WhitePointChromaticityY (0x55D8): White point chromaticity coordinate Y.

Luminance Range Elements

The mastering display’s operational brightness range is represented in candelas per square meter (\(\text{cd/m}^2\), or nits) via two floating-point elements inside MasteringMetadata:

  • LuminanceMax (0x55D9): Maximum luminance capability of the mastering monitor (e.g., 1000.0 or 4000.0).
  • LuminanceMin (0x55DA): Minimum luminance capability of the mastering monitor (e.g., 0.0001 or 0.005).

Relationship to Content Light Levels

While SMPTE 2086 strictly covers the mastering display parameters detailed above, static HDR metadata in WebM often accompanies CTA-861.3 content light levels. Content-specific values such as Maximum Content Light Level (MaxCLL, ID 0x55BC) and Maximum Frame-Average Light Level (MaxFALL, ID 0x55BD) are stored as unsigned integers directly under the parent Colour element rather than inside MasteringMetadata.
