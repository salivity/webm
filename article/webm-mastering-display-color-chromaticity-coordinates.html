WebM Mastering Display Color Chromaticity Coordinates

The WebM container format incorporates High Dynamic Range (HDR) mastering metadata by adapting structural elements from the Matroska specification. This article explains how WebM defines mastering display color chromaticity coordinates, detailing the underlying Extensible Binary Meta Language (EBML) schema, the specific CIE 1931 coordinate elements used for primary colors and the white point, and their compliance with the SMPTE ST 2086 standard.

Container Hierarchy and EBML Architecture

WebM inherits its metadata structure directly from Matroska. Mastering display characteristics are mapped inside the video track element using a nested hierarchy:

  • Segment (0x18538067)
    • Tracks (0x1654AE6B)
      • TrackEntry (0xAE)
        • Video (0xE0)
          • Colour (0x55B0)
            • MasteringMetadata (0x55D0)

The Colour element encompasses general color properties (such as matrix coefficients, transfer characteristics, and color range), while the nested MasteringMetadata element houses the exact static display characteristics of the monitor used to master the content.

Chromaticity Coordinate Elements

To define the mastering display’s color gamut, the WebM specification provides eight discrete EBML elements inside MasteringMetadata. These elements represent the normalized \(x\) and \(y\) coordinates in the standard CIE 1931 chromaticity space:

  • Red Primary:
    • PrimaryRChromaticityX (0x55D1): The red \(x\) chromaticity coordinate.
    • PrimaryRChromaticityY (0x55D2): The red \(y\) chromaticity coordinate.
  • Green Primary:
    • PrimaryGChromaticityX (0x55D3): The green \(x\) chromaticity coordinate.
    • PrimaryGChromaticityY (0x55D4): The green \(y\) chromaticity coordinate.
  • Blue Primary:
    • PrimaryBChromaticityX (0x55D5): The blue \(x\) chromaticity coordinate.
    • PrimaryBChromaticityY (0x55D6): The blue \(y\) chromaticity coordinate.
  • White Point:
    • WhitePointChromaticityX (0x55D7): The white point \(x\) chromaticity coordinate.
    • WhitePointChromaticityY (0x55D8): The white point \(y\) chromaticity coordinate.

Data Types and Value Representation

In the WebM binary structure, all chromaticity coordinate elements are defined as EBML float data types (typically 32-bit single-precision or 64-bit double-precision IEEE 754 floats).

Unlike integer-scaled specifications where values are pre-multiplied (such as the 0.00002 increments specified in raw ITU-T H.264/H.265 SEI messages), WebM stores these coordinates directly as normalized floating-point numbers between 0.0 and 1.0. For example, a standard D65 white point (\(x = 0.3127, y = 0.3290\)) is directly stored as 0.3127 and 0.3290.

Relationship to SMPTE ST 2086

WebM’s implementation of these elements directly fulfills the color volume requirements defined in SMPTE ST 2086 ("Mastering Display Color Volume Metadata Supporting High Luminance and Wide Color Gamut Images"). Together with LuminanceMin (0x55D9) and LuminanceMax (0x55DA), these chromaticity coordinates provide downstream decoders, operating systems, and display panels with the precise color volume boundaries of the reference mastering monitor, enabling accurate gamut mapping and tone compression during playback.
