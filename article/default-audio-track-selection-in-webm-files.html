Default Audio Track Selection in WebM Files

This article provides a direct breakdown of the container attributes within multi-language WebM files that govern automated audio stream selection. WebM is a restricted subset of the Matroska (MKV) format, utilizing Extensible Binary Meta Language (EBML). To manage multi-language playback, media players evaluate metadata defined within each audio stream's TrackEntry element to determine which audio track should be activated by default.

Key EBML Attributes in TrackEntry

The default audio selection is dictated by four primary track-level elements located inside the WebM Tracks master element:

1. FlagDefault (EBML ID: 0x88)

The FlagDefault element is a single-bit boolean indicator (1 or 0) that marks a track as the author’s intended default.

  • A value of 1 indicates that the media player should automatically select this track if no user preferences override it.
  • A value of 0 indicates the track should not be activated automatically.
  • Under WebM and Matroska specifications, only one audio track should ideally have FlagDefault set to 1. If multiple tracks have FlagDefault set to 1, the behavior depends on the player, which typically falls back to the track order.

2. Language (EBML ID: 0x22B59C) and LanguageIETF (EBML ID: 0x22B59D)

These elements declare the spoken language of the audio stream.

  • Language uses a legacy 3-letter ISO 639-2 code (e.g., eng, spa, jpn).
  • LanguageIETF uses the modern BCP 47 language tag syntax (e.g., en-US, es-ES). While not a direct "default" flag, these attributes dictate track selection because most media playback engines prioritize matching the user’s system or application language preferences before evaluating FlagDefault.

3. FlagForced (EBML ID: 0x55AA)

While primarily used for forced narrative subtitles, FlagForced is also a valid boolean flag for audio tracks in modern Matroska/WebM parsing. If a track is marked as forced (1), it indicates content that must be played if no other primary track matches the configuration, such as a director's commentary track or visual description track linked to specific accessibility profiles.

4. TrackNumber (EBML ID: 0xD7) and Container Order

When no track is explicitly tagged with FlagDefault = 1, or when no tracks match the player's preferred language, players fall back to structural sequence. The playback engine will select the first audio track encountered in the container, generally identified by the lowest TrackNumber or earliest byte position in the Tracks header.

Player Track Resolution Priority

Most compliant players (such as browser engines using FFmpeg, Chromium, or GStreamer) evaluate these attributes in the following order:

  1. User Preference + Language Match: The player checks for audio tracks where Language or LanguageIETF matches the user's preferred playback language.
  2. Language Match + Default Flag: If multiple tracks match the user's language, the player chooses the track with FlagDefault set to 1.
  3. Global Default Flag: If no language match occurs, the player selects the audio track with FlagDefault = 1, regardless of language.
  4. Fallback (First Track): If no audio tracks have FlagDefault = 1 and no language matches exist, the player selects the first audio track declared in the file.
