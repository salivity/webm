FFmpeg Flags for Visually Lossless WebM Archival

This article provides the exact FFmpeg command-line flags required to encode visually lossless WebM files for archival purposes. By leveraging the VP9 video codec in Constant Quality mode alongside high-fidelity audio encoding, you can preserve master-grade visual quality while maintaining broad open-source container compatibility.

The Recommended Visually Lossless Command

To create a visually lossless WebM file using the standard VP9 video codec and Opus audio, use the following command:

ffmpeg -i input.mov -c:v libvpx-vp9 -crf 15 -b:v 0 -deadline best -pix_fmt yuv420p -c:a libopus -b:a 256k output.webm

Breakdown of Required Flags

  • -c:v libvpx-vp9: Specifies the standard VP9 video encoder used within the WebM container format.
  • -crf 15: Sets the Constant Rate Factor. In VP9, CRF values range from 0 to 63. A value of 15 to 18 is considered visually indistinguishable from the source (visually lossless). Lower values increase quality and file size.
  • -b:v 0: Enforces pure Constant Quality (CQ) mode. When -b:v is set to 0 alongside a -crf value, the encoder prioritizes quality above all else and removes bitrate constraints.
  • -deadline best: Instructs the encoder to use the highest quality algorithms, ignoring encoding speed. For archival, where encode time is secondary to compression efficiency and artifact reduction, best is the optimal setting.
  • -pix_fmt yuv420p: Sets standard pixel chroma subsampling to ensure playback compatibility across media players and web browsers. For preserving 10-bit master content, use -pix_fmt yuv420p10le.
  • -c:a libopus: Encodes audio using the Opus codec, the standard high-fidelity audio format for WebM.
  • -b:a 256k: Allocates 256 kbps for stereo audio, providing transparent, indistinguishable sound reproduction for archiving.

Alternative: Mathematical Lossless Mode

If your archival workflow requires exact bit-for-bit mathematical losslessness rather than visually lossless compression, enable VP9's dedicated lossless mode and combine it with FLAC audio:

ffmpeg -i input.mov -c:v libvpx-vp9 -lossless 1 -deadline best -pix_fmt yuv444p -c:a flac output.webm
  • -lossless 1: Enables VP9's true mathematical lossless compression mode.
  • -pix_fmt yuv444p: Retains full 4:4:4 chroma information without downsampling.
  • -c:a flac: Replaces Opus with FLAC to ensure bit-perfect, uncompressed audio preservation within the WebM container.
