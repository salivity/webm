VP8 DCT Sizes in WebM Intra-Prediction Modes

The WebM VP8 video codec utilizes a fixed 4x4 Discrete Cosine Transform (DCT) size across all intra-prediction modes. Unlike more complex or modern codecs that dynamically vary transform block dimensions between 4x4, 8x8, or larger sizes, VP8 standardizes its primary frequency transform on a 4x4 grid. This article details how this 4x4 DCT architecture operates across VP8 intra-prediction block types and how secondary transforms handle low-frequency data.

Core Transform Architecture: The 4x4 DCT

Regardless of whether an intra-predicted block is evaluated at the sub-block level or the full macroblock level, VP8 divides the prediction residual into uniform 4x4 blocks before applying frequency transformation. The primary transform implemented is a 4x4 integer approximation of the type-II Discrete Cosine Transform.

VP8 supports two primary luma intra-prediction configurations and one chroma configuration:

  • 4x4 Luma Intra-Prediction (Sub-blocks): The 16x16 luma macroblock is broken into sixteen individual 4x4 sub-blocks. Each sub-block selects one of 10 intra-prediction directions. The residual difference for each 4x4 sub-block is directly transformed using a single 4x4 DCT.
  • 16x16 Luma Intra-Prediction (Full Macroblock): The macroblock predicts the entire 16x16 area as a whole using one of four directional modes (DC, Vertical, Horizontal, or TrueMotion). The resulting 16x16 residual is segmented into sixteen 4x4 blocks, each undergoing a 4x4 DCT.
  • 8x8 Chroma Intra-Prediction: Chrominance channels (U and V) operate on 8x8 blocks, utilizing one of four prediction modes. Each 8x8 chroma block is segmented into four 4x4 blocks, each transformed using the 4x4 DCT.

Secondary Transforms: Walsh-Hadamard Transform (WHT)

While the DCT size itself never deviates from 4x4, VP8 applies a secondary transform to capture low-frequency energy across larger areas when using full-macroblock intra-prediction:

  • Luma DC Transform: When 16x16 intra-prediction is active, the DC coefficients from each of the sixteen 4x4 DCT blocks are collected into a separate 4x4 matrix. This matrix is transformed using a 4x4 Walsh-Hadamard Transform (WHT).
  • Chroma DC Transform: For the 8x8 chroma blocks, the DC coefficients from the four 4x4 DCT blocks are gathered into a 2x2 matrix and transformed using a 2x2 WHT.

Summary

VP8 restricts its DCT operations strictly to a 4x4 size for all intra-prediction residual coding. Coarser spatial correlations in 16x16 luma and 8x8 chroma modes are not handled by larger DCTs, but instead through secondary Walsh-Hadamard transforms performed on the DC coefficients of the base 4x4 DCT blocks.
