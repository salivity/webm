Inspect VP9 Frame Headers in WebM Bitstreams

Unlike H.264 and HEVC, the VP9 video codec does not use dedicated Sequence Parameter Set (SPS) or Picture Parameter Set (PPS) NAL units. Instead, VP9 embeds equivalent global sequence configurations, color parameters, and frame-level decoding flags within the WebM container’s CodecPrivate element and the uncompressed header of keyframes. Inspecting these parameters requires specific command-line utilities and bitstream analyzers capable of demuxing WebM (EBML) and parsing raw VP9 bitstreams.

Understanding VP9's SPS/PPS Equivalent

In VP9, sequence-level parameters—such as profile, bit depth, color space, subsampling, and frame dimensions—are located in two places:

  1. WebM CodecPrivate Element: Contains the vpcC (VP Codec Configuration) metadata, defining the VP9 profile, level, bit depth, and colorimetry at the container level.
  2. Uncompressed Frame Header: Every keyframe (intra-frame) begins with an uncompressed header containing the sync code (0xD5C6B0), profile, frame dimensions, render size, tiling layout, and loop filter settings.

The following tools allow you to inspect this metadata at varying levels of detail.

1. FFmpeg and FFprobe

FFprobe provides deep visibility into both container metadata and individual frame headers.

  • Trace-level Header Parsing: Using the -v trace flag forces FFprobe to log the decoding process, displaying exact syntax elements parsed from the uncompressed VP9 frame header:

    ffprobe -v trace -show_frames -select_streams v:0 input.webm

    Look for the VP9 frame header breakdown, which details profile, frame_type (keyframe/inter), bit_depth, color_space, tile_cols, and tile_rows.

  • Structured Frame Inspection: To extract high-level sequence configurations and color properties in JSON format:

    ffprobe -v error -select_streams v:0 -show_frames -show_entries frame=key_frame,pict_type,width,height,color_space,color_primaries,color_transfer -of json input.webm

2. MKVToolNix (mkvinfo)

Since WebM is a restricted subset of the Matroska (MKV) container, MKVToolNix provides exact inspection of the EBML elements where stream-level parameters are initialized.

  • Container and CodecPrivate Inspection: 
    mkvinfo -v -v input.webm
    In the output, navigate to the Track element with TrackType: video. Inspect:
    • CodecID: Set to V_VP9.
    • CodecPrivate: Contains the raw byte array representing the VP9 configuration block.
    • PixelWidth, PixelHeight, and Colour elements (matrix coefficients, transfer characteristics, and primaries).

3. MediaInfo

MediaInfo parses both the WebM container and the initial VP9 frame headers to provide a consolidated summary of the sequence settings.

  • Full Metadata Dump: 
    mediainfo -f input.webm
    The video section reports values derived from the uncompressed header:
    • Format profile: Profile 0, 1, 2, or 3.
    • Format level: Corresponds to the VP9 operational tier and level.
    • Color space, ChromaSubsampling, and BitDepth.

4. Libvpx Reference Tools (vpxdec)

The official reference implementation from the WebM Project includes decoders and dumpers capable of processing raw bitstream structures.

  • Extract the raw VP9 stream using mkvextract: 
    mkvextract tracks input.webm 0:video.vp9
  • Parse the bitstream with vpxdec: 
    vpxdec --summary --verbose video.vp9 -o /dev/null
    Adding the --verbose flag prints frame types, spatial resolutions, quantization parameters, and tile configurations directly from the uncompressed header per frame.

5. Dedicated Graphical Bitstream Analyzers

For visual frame-by-frame inspection of the bitstream syntax:

  • Elecard StreamEye: Supports VP9 inside WebM. It visualizes the uncompressed header fields, transform block partitions, motion vectors, quantization scales, and loop filtering parameters.
  • Intel Video Pro Analyzer (Intel VPA): Directly inspects VP9 WebM files, breaking down the bitstream into sequence properties, frame header syntax trees, segmentation maps, and probability tables.
