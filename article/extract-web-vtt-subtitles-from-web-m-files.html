Extract WebVTT Subtitles from WebM Files

WebM files frequently store embedded WebVTT (Web Video Text Tracks) subtitle streams alongside their audio and video content. Extracting these subtitles into standalone .vtt files is straightforward using command-line utilities such as FFmpeg and MKVToolNix. This guide demonstrates how to inspect the embedded streams inside a WebM container and extract the WebVTT tracks directly without re-encoding media files.

Method 1: Using FFmpeg

FFmpeg is a versatile multimedia framework capable of demuxing and copying subtitle streams from WebM containers.

1. Identify the Subtitle Track

Before extraction, inspect the file to determine which stream contains the subtitles:

ffprobe -hide_banner input.webm

Look for a stream labeled Subtitle: webvtt. Note its stream index (for example, 0:s:0 for the first subtitle stream, or an absolute index like 0:2).

2. Extract the WebVTT Track

Run the following command to copy the subtitle stream into an external .vtt file without modifying the data:

ffmpeg -i input.webm -map 0:s:0 -c:s copy output.vtt
  • -i input.webm: Specifies the source file.
  • -map 0:s:0: Targets the first subtitle stream. If the file has multiple languages, change the final digit (e.g., 0:s:1 for the second track).
  • -c:s copy: Copies the subtitle stream directly without re-encoding.
  • output.vtt: Designates the destination file name.

Method 2: Using MKVToolNix (mkvextract)

Because the WebM container is a restricted subset of the Matroska (MKV) format, MKVToolNix tools natively parse WebM files.

1. Identify the Track ID

Use mkvmerge to view the internal track IDs:

mkvmerge -i input.webm

The output will display the tracks with an assigned numeric Track ID, for example: Track ID 2: subtitles (WebVTT)

2. Extract with mkvextract

Using the Track ID found in the previous step, extract the subtitle stream:

mkvextract tracks input.webm 2:output.vtt

Replace 2 with the actual Track ID reported by mkvmerge.

Handling Multiple Subtitle Tracks

If a WebM file contains multiple subtitle streams (such as different language options), map them individually:

ffmpeg -i input.webm -map 0:s:0 -c:s copy english.vtt -map 0:s:1 -c:s copy spanish.vtt

This single command splits each specified stream into its own separate WebVTT file simultaneously.
