Embed Custom Metadata in WebM Files with MKVToolNix

Embedding custom metadata tags into WebM files allows you to organize media libraries, add licensing information, and specify track details without altering the underlying video or audio streams. Because the WebM format is a specialized subset of the Matroska (MKV) container specification, the MKVToolNix suite can directly read and write metadata to WebM files. This guide demonstrates how to create a compliant XML tag file and write custom metadata tags directly into WebM containers using MKVToolNix command-line tools.

1. Create the XML Metadata File

MKVToolNix uses a structured XML format to define custom and standard metadata tags. Create a new text file named tags.xml and define your custom tags using the Matroska XML tagging structure:

<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE Tags SYSTEM "matroskatags.dtd">
<Tags>
  <Tag>
    <Targets>
      <!-- TargetTypeValue 50 applies tags globally to the entire movie/file -->
      <TargetTypeValue>50</TargetTypeValue>
    </Targets>
    <Simple>
      <Name>TITLE</Name>
      <String>Sample WebM Video</String>
    </Simple>
    <Simple>
      <Name>ARTIST</Name>
      <String>Jane Doe</String>
    </Simple>
    <Simple>
      <Name>CUSTOM_TAG_NAME</Name>
      <String>Custom Tag Value</String>
    </Simple>
    <Simple>
      <Name>LICENSE</Name>
      <String>Creative Commons Attribution 4.0</String>
    </Simple>
  </Tag>
</Tags>

2. Embed Metadata In-Place Using mkvpropedit

The fastest way to embed metadata into an existing WebM file without re-muxing is using mkvpropedit. This tool modifies the WebM header directly.

Run the following command in your terminal:

mkvpropedit "input.webm" --tags global:"tags.xml"

To replace or set track-specific metadata (such as tagging an audio or video stream specifically), target the track number:

mkvpropedit "input.webm" --tags track:v1:"tags.xml"

3. Embed Metadata During Muxing Using mkvmerge

If you are assembling a WebM file from separate streams or wish to output a new file rather than editing in-place, use mkvmerge:

mkvmerge -o "output.webm" --global-tags "tags.xml" "input.webm"

4. Verify the Embedded Tags

To verify that the custom tags have been successfully written to the WebM container, inspect the file using mkvinfo or the MKVToolNix GUI:

mkvinfo "input.webm"

The output will display the tag elements, their target levels, and the associated key-value pairs stored within the WebM container.
