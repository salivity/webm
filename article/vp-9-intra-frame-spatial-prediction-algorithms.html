VP9 Intra-Frame Spatial Prediction Algorithms

VP9 intra-frame spatial prediction reduces spatial redundancy within individual video frames by reconstructing block pixels using surrounding, previously decoded boundary pixels. To accomplish this inside the WebM container, the VP9 codec implements ten discrete prediction modes governed by exact mathematical algorithms: eight directional angular extrapolation modes, a DC averaging mode, and a TrueMotion plane prediction mode.

Directional Prediction and Sub-Pixel Interpolation

VP9 supports eight directional modes categorized by projection angles: Vertical, Horizontal, and six diagonal angles (D45, D63, D117, D135, D153, and D207, representing their respective degree approximations).

Directional prediction algorithms project neighbor pixels from the top row (\(A\)) and left column (\(L\)) into the target block along a specified angle vector. Because the projection vector often falls between discrete integer pixel coordinates, VP9 uses a fixed-point linear interpolation algorithm with 1/16th-pixel precision (sub-pel accuracy):

\[P(x, y) = ((16 - f) \cdot S_i + f \cdot S_{i+1} + 8) \gg 4\]

Where:

  • \(P(x,y)\) is the predicted pixel at coordinate \((x,y)\).
  • \(S_i\) and \(S_{i+1}\) are adjacent reconstructed reference samples from the boundary.
  • \(f\) represents the fractional phase index (\(0 \le f < 16\)) calculated from the projection angle and coordinates.
  • \(\gg 4\) performs an integer bit-shift equivalent to division by 16 with rounding (\(+ 8\)).

TrueMotion Prediction Mode (TM_PRED)

Inherited from the VP3 codec and refined in VP9, TrueMotion models smooth gradients across the block by assuming horizontal and vertical pixel deltas remain constant across two-dimensional space. It calculates each predicted pixel using the top reference pixel, the left reference pixel, and the top-left corner reference pixel (\(TL\)):

\[P(x, y) = \text{Clip1}(L(y) + A(x) - TL)\]

Where:

  • \(L(y)\) is the reference pixel in the left boundary column at row \(y\).
  • \(A(x)\) is the reference pixel in the above boundary row at column \(x\).
  • \(TL\) is the diagonally adjacent top-left corner pixel.
  • \(\text{Clip1}(\cdot)\) constrains the output to the valid bit-depth range (e.g., \(0\) to \(255\) for 8-bit video).

DC Prediction Mode (DC_PRED)

DC prediction fills the target block with a single uniform value calculated as the arithmetic mean of all available adjacent boundary pixels.

When both above and left neighbors are available for a block of size \(N \times N\), the algorithm calculates:

\[DC = \left( \sum_{x=0}^{N-1} A(x) + \sum_{y=0}^{N-1} L(y) + N \right) \gg (\log_2(N) + 1)\]

If only the top or left boundary is available due to frame or tile edges, the calculation sums the available edge and divides by \(N\) using a bit-shift:

\[DC = \left( \sum_{i=0}^{N-1} S(i) + \frac{N}{2} \right) \gg \log_2(N)\]

If no neighbor pixels are available, the default midpoint value (\(128\) for 8-bit depth) is assigned.

Boundary Reference Smoothing

Before applying directional interpolation, VP9 applies a low-pass filter to the reference boundary array to eliminate high-frequency noise that could cause visual artifacts. This smoothing utilizes a 3-tap finite impulse response (FIR) filter with weights \([1, 2, 1]\):

\[S'_k = (S_{k-1} + 2 \cdot S_k + S_{k+1} + 2) \gg 2\]

This pre-filtering step stabilizes the spatial extrapolations used across larger transform block sizes ranging from \(4\times4\) up to \(32\times32\) pixels.
