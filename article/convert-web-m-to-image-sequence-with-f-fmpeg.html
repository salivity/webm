Convert WebM to Image Sequence with FFmpeg

This guide explains how to extract an image sequence from an animated WebM file using FFmpeg. You will learn the fundamental command syntax to export frames as PNG or JPEG images, along with options to control frame rates, select specific time ranges, and preserve transparency.

Basic Command to Extract Frames

To extract every frame from a WebM file into individual images, open your terminal or command prompt and run the following command:

ffmpeg -i input.webm frame_%04d.png
  • -i input.webm: Specifies the path to your source WebM file.
  • frame_%04d.png: Defines the output filename pattern. %04d creates a four-digit, zero-padded numbering sequence (e.g., frame_0001.png, frame_0002.png).

Preserving Transparency with PNG

Animated WebM files often include an alpha channel (transparent background). Exporting to PNG format automatically preserves this transparency. If you do not require transparency, you can output to JPEG format instead:

ffmpeg -i input.webm -q:v 2 frame_%04d.jpg
  • -q:v 2: Controls the JPEG image quality (values range from 1 to 31, where 1–3 provides near-lossless quality).

Extracting Frames at a Specific Frame Rate

If you only need a subset of frames rather than every single frame, use the fps video filter to specify how many images to capture per second:

ffmpeg -i input.webm -vf "fps=1" frame_%04d.png
  • -vf "fps=1": Extracts exactly one frame per second.
  • To extract one frame every 5 seconds, use -vf "fps=1/5".

Extracting from a Specific Time Range

To extract frames from a defined portion of the video, use the -ss (start time) and -to or -t (duration) flags before the input file:

ffmpeg -ss 00:00:02 -to 00:00:06 -i input.webm frame_%04d.png
  • -ss 00:00:02: Starts extraction at the 2-second mark.
  • -to 00:00:06: Stops extraction at the 6-second mark.
