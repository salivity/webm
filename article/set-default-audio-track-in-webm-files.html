Set Default Audio Track in WebM Files

Modifying the default audio track flag in a WebM container allows media players to automatically select your preferred audio stream during playback. Because WebM is based on the Matroska (MKV) format, you can easily change these track flags without re-encoding the video or audio streams. This guide covers how to set the default audio track using command-line tools like mkvpropedit and FFmpeg, as well as a graphical interface.

Method 1: Using mkvpropedit (Fastest, In-Place Edit)

mkvpropedit is part of the MKVToolNix suite. It modifies the container metadata directly without remuxing the entire file, completing the operation in seconds.

Step 1: Identify Track IDs

Check the track numbers and current flags using mkvmerge:

mkvmerge -i input.webm

You will see output listing the tracks, such as:

  • Track ID 0: video (VP9)
  • Track ID 1: audio (Opus)
  • Track ID 2: audio (Opus)

Step 2: Update the Default Track Flag

To set the second audio track as the default and remove the default flag from the first audio track, run:

mkvpropedit input.webm --edit track:a1 --set flag-default=0 --edit track:a2 --set flag-default=1
  • track:a1 refers to the first audio track.
  • track:a2 refers to the second audio track.
  • flag-default=1 marks the track as default; flag-default=0 removes the default status.

Method 2: Using FFmpeg (Remuxing)

If you have FFmpeg installed, you can use the -disposition parameter to set the default track. This method remuxes the file into a new container while copying all streams without re-encoding.

Run the following command:

ffmpeg -i input.webm -map 0 -c copy -disposition:a:0 0 -disposition:a:1 default output.webm
  • -map 0 includes all streams from the input file.
  • -c copy copies the streams without re-encoding.
  • -disposition:a:0 0 removes the default flag from the first audio stream (index 0).
  • -disposition:a:1 default sets the default flag on the second audio stream (index 1).

Method 3: Using MKVToolNix GUI (Visual Editor)

If you prefer a graphical interface:

  1. Open MKVToolNix GUI.
  2. Go to the Header editor tab from the left sidebar.
  3. Click Open Matroska or WebM file and select your .webm file.
  4. Expand the audio track you want to disable by default, select "Default track" flag, change its value to No, and check the enable box.
  5. Expand the audio track you want to make the default, select "Default track" flag, change its value to Yes, and check the enable box.
  6. Click Header editor in the top menu and select Save.
