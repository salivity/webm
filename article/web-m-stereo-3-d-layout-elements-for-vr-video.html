WebM Stereo 3D Layout Elements for VR Video

This article provides an overview of how the WebM container specifies stereoscopic 3D layouts for virtual reality and immersive media. Built upon the Matroska (EBML) specification, WebM relies on specific metadata tags nested inside the video track headers to signal how left- and right-eye views are arranged. Understanding these structural elements ensures VR players and headsets can accurately unpack, decode, and project stereoscopic content to each eye.

The Core Structural Hierarchy

WebM organizes data using Extensible Binary Meta Language (EBML). To define the stereo 3D layout, WebM places metadata inside the video track definition. The structural path follows this hierarchy:

Segment (0x18538067)
└── Tracks (0x1654AE6B)
    └── TrackEntry (0xAE)
        └── Video (0xE0)
            └── StereoMode (0x53B8)

The StereoMode element (Element ID 0x53B8) is an unsigned integer that explicitly tells the media parser how the two stereoscopic images are packed into the video stream.

Common StereoMode Values in VR

While the Matroska specification supports numerous stereoscopic arrangements (including anaglyph and field-sequential modes), VR production primarily relies on side-by-side and top-bottom configurations.

The primary StereoMode values used for VR are:

  • 0 (Mono): Default mono 2D video (no stereoscopic depth).
  • 1 (Side-by-Side, Left Eye First): The left-eye frame occupies the left half of the video, and the right-eye frame occupies the right half.
  • 2 (Top-Bottom, Right Eye First): The right-eye frame occupies the top half, and the left-eye frame occupies the bottom half.
  • 3 (Top-Bottom, Left Eye First): The left-eye frame occupies the top half, and the right-eye frame occupies the bottom half (the most common standard for top-bottom VR180/VR360).
  • 11 (Side-by-Side, Right Eye First): The right-eye frame occupies the left half, and the left-eye frame occupies the right half.

Supplemental VR Projection Elements

For full 360-degree or 180-degree VR playback, StereoMode works in conjunction with the Matroska Projection element, which is also located inside the Video master element:

  • Projection (0x7670): Master element containing geometric mapping data.
  • ProjectionType (0x7671): Defines the mapping format, such as 0 for rectangular (standard flat), 1 for equirectangular (common in 360 VR), 2 for cubemap, and 3 for mesh-based geometry.
  • ProjectionPoseYaw, ProjectionPosePitch, ProjectionPoseRoll (0x7674 - 0x7676): Define default orientation offsets for VR positioning.

When a VR player encounters a WebM file, it reads the StereoMode element to divide the decoded video frames into separate eye channels, then applies the geometry defined in ProjectionType to render the immersive environment to the headset displays.
