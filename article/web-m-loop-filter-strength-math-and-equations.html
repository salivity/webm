WebM Loop Filter Strength Math and Equations

This article explains the mathematical functions and algorithms used to calculate loop filter strength in WebM video codecs (VP8 and VP9). The deblocking loop filter removes visual discontinuities along block boundaries caused by discrete cosine transform (DCT) quantization. The underlying mathematics rely on multi-parameter baseline adjustments, threshold derivations using bit shifts and clamping, boundary edge variance tests, and bounded non-linear adjustment functions to smooth pixel transitions without destroying real image edges.

1. Macroblock Filter Level Calculation

Before individual pixels are evaluated, the codec determines the effective filter level (\(L\)) for a given macroblock or transform block. This value is computed by adding frame-level base values and context-specific deltas, bounded within a predefined range:

\[L = \text{Clamp}_{0}^{63}\left( L_{\text{frame}} + \Delta_{\text{segment}} + \Delta_{\text{ref}} + \Delta_{\text{mode}} \right)\]

  • \(L_{\text{frame}}\): Base loop filter level transmitted in the frame header.
  • \(\Delta_{\text{segment}}\): Segment-specific delta level.
  • \(\Delta_{\text{ref}}\): Delta applied based on the reference frame (e.g., Intra, Last, Golden, AltRef).
  • \(\Delta_{\text{mode}}\): Delta determined by the prediction mode (e.g., B_PRED, ZeroMV).
  • \(\text{Clamp}_{A}^{B}(x) = \min(B, \max(A, x))\): Clamping operator constraining \(L\) to the range \([0, 63]\).

2. Derivation of Filter Thresholds

The effective filter level \(L\) is used to derive two primary threshold values: the edge limit (\(E\)) and the interior limit (\(I\)). These thresholds are modified by the frame's sharpness level (\(S \in [0, 7]\)):

\[E = \begin{cases} L & \text{if } S = 0 \\ \text{Clamp}_{1}^{255}\left( \lfloor L \cdot 2^{-1} \rfloor \right) & \text{if } S > 0 \text{ and high sharpness} \\ \text{Clamp}_{1}^{255}\left( \lfloor L \cdot 2^{-(S > 4 ? 2 : 1)} \rfloor \right) & \text{general scaling} \end{cases}\]

The interior threshold \(I\) controls smoothing within the block interior:

\[I = \text{Clamp}_{1}^{255}\left( \lfloor L \cdot 2^{-2} \rfloor \right)\]

For chroma channels, \(L\) is often scaled down (\(L_{\text{chroma}} = \lfloor L \cdot \frac{2}{3} \rfloor\)) prior to threshold derivation.

3. Edge Filtering Condition (Variance Detection)

To determine whether an edge needs filtering, the codec evaluates the absolute difference of four reconstructed pixels across the boundary: \(p_1, p_0\) on the left/above and \(q_0, q_1\) on the right/below. Filtering is applied only if the edge satisfies the inequality:

\[2 \cdot |p_0 - q_0| + \left\lfloor \frac{|p_1 - q_1|}{2} \right\rfloor \le E\]

Additionally, to prevent smoothing across true image edges, the interior samples must satisfy:

\[|p_1 - p_0| \le I \quad \text{and} \quad |q_1 - q_0| \le I\]

If all conditions evaluate to true, filtering proceeds; otherwise, the boundary is left unmodified.

4. Pixel Modification Function

When the conditions are met, the adjustment delta (\(\Delta\)) applied to the boundary pixels \(p_0\) and \(q_0\) is computed using a bounded linear difference:

\[X = 3 \cdot (q_0 - p_0) + (p_1 - q_1)\]

For standard (normal) filtering without high-edge variance, \(X\) is scaled, clamped, and shifted:

\[\Delta = \text{Clamp}_{-L}^{L}\left( \left\lfloor \frac{X + 4}{8} \right\rfloor \right)\]

The reconstructed pixel values \(p_0'\) and \(q_0'\) are updated symmetrically:

\[p_0' = \text{Clamp}_{0}^{255}(p_0 + \Delta)\] \[q_0' = \text{Clamp}_{0}^{255}(q_0 - \Delta)\]

When higher-order filters (wide filters) are activated in flat regions, the calculation expands to include additional outer taps (\(p_2, p_3, q_2, q_3\)) using weighted averages such as:

\[p_0' = \left\lfloor \frac{p_2 \cdot 1 + p_1 \cdot 2 + p_0 \cdot 2 + q_0 \cdot 2 + q_1 \cdot 1 + 4}{8} \right\rfloor\]

This combination of piecewise threshold checks and clamped differential math allows WebM codecs to suppress blocking artifacts dynamically based on local spatial variance and frame-level quantization parameters.
