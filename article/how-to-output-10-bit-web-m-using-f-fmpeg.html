How to Output 10-Bit WebM Using FFmpeg

Encoding WebM video with 10-bit color precision using FFmpeg eliminates color banding in gradients and enables High Dynamic Range (HDR) playback. The WebM container supports 10-bit color primarily through the VP9 and AV1 codecs. Achieving 10-bit output requires setting a 10-bit pixel format, selecting an appropriate encoder profile, and configuring the correct container output parameters.

Encoding 10-Bit WebM with VP9

VP9 is the standard codec for WebM files and natively supports 10-bit color precision through Profile 2. When using the libvpx-vp9 encoder, you must explicitly set the pixel format and profile.

Standard Command

ffmpeg -i input.mp4 -c:v libvpx-vp9 -pix_fmt yuv420p10le -profile:v 2 -crf 30 -b:v 0 -c:a libopus -b:a 128k output_10bit.webm

Parameter Breakdown

  • -c:v libvpx-vp9: Selects the VP9 video encoder.
  • -pix_fmt yuv420p10le: Sets the pixel format to 10-bit Little Endian YUV 4:2:0.
  • -profile:v 2: Forces VP9 Profile 2, which is required for 10-bit and 12-bit color depth with 4:2:0 chroma subsampling.
  • -crf 30 -b:v 0: Enables Constant Quality mode. Recommended CRF values for VP9 range from 15 to 35 (lower values yield higher quality).
  • -c:a libopus -b:a 128k: Encodes audio to Opus at 128 kbps, the recommended audio format for WebM.

Encoding 10-Bit WebM with AV1

AV1 offers superior compression efficiency compared to VP9 and supports 10-bit precision natively. You can encode 10-bit AV1 inside a WebM container using libsvtav1 (faster) or libaom-av1 (reference encoder).

SVT-AV1 Command (Recommended)

ffmpeg -i input.mp4 -c:v libsvtav1 -pix_fmt yuv420p10le -crf 28 -preset 6 -c:a libopus -b:a 128k output_av1_10bit.webm

libaom-AV1 Command

ffmpeg -i input.mp4 -c:v libaom-av1 -pix_fmt yuv420p10le -strict -2 -crf 28 -b:v 0 -c:a libopus -b:a 128k output_aom_10bit.webm

Parameter Breakdown

  • -c:v libsvtav1: Uses the high-performance Scalable Video Technology AV1 encoder.
  • -preset 6: Sets the encoding speed/efficiency tradeoff for SVT-AV1 (values range from 0 to 13; 4 to 7 are common for balanced encoding).
  • -crf 28: Sets the target visual quality (typical range: 20 to 35).

Preserving HDR Metadata (Optional)

If your source contains HDR10 metadata, include color space and transfer characteristic flags to prevent colors from washing out:

ffmpeg -i input_hdr.mp4 -c:v libvpx-vp9 -pix_fmt yuv420p10le -profile:v 2 \
  -color_primaries bt2020 \
  -color_trc smpte2084 \
  -colorspace bt2020nc \
  -crf 28 -b:v 0 -c:a copy output_hdr_10bit.webm
  • -color_primaries bt2020: Identifies the BT.2020 color gamut.
  • -color_trc smpte2084: Specifies the PQ (Perceptual Quantizer) transfer function.
  • -colorspace bt2020nc: Specifies non-constant luminance BT.2020 color matrix.

Verifying 10-Bit Output

To confirm that the output file was encoded with 10-bit depth, run ffprobe:

ffprobe -v error -show_entries stream=pix_fmt,profile -of default=noprint_wrappers=1 output_10bit.webm

The output should display pix_fmt=yuv420p10le and profile=Profile 2 (for VP9) or profile=Main (for AV1).
