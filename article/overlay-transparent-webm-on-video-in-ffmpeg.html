Overlay Transparent WebM on Video in FFmpeg

This guide provides the exact FFmpeg command and filter syntax required to overlay a transparent WebM video onto another video track. You will learn how to properly construct the -filter_complex overlay graph, ensure the alpha channel (transparency) is accurately decoded using the VP8 or VP9 decoder, and configure positioning and timing parameters.

The Standard Overlay Command

To overlay a transparent WebM file (overlay.webm) on top of a base video (background.mp4), use the following command:

ffmpeg -i background.mp4 -c:v libvpx-vp9 -i overlay.webm -filter_complex "[0:v][1:v]overlay=0:0:format=auto[outv]" -map "[outv]" -map 0:a? -c:v libx264 -crf 18 -c:a copy output.mp4

Breakdown of the Syntax

  • -i background.mp4: Defines the main background video as input stream 0.
  • -c:v libvpx-vp9 -i overlay.webm: Explicitly instructs FFmpeg to use the libvpx-vp9 decoder for the second input (overlay.webm). Specifying the decoder before the input ensures that the embedded alpha channel (transparency) is decoded properly instead of being rendered as black. If your WebM uses VP8, replace libvpx-vp9 with libvpx.
  • -filter_complex: Invokes the filtergraph:
    • [0:v][1:v]: Takes the video stream from the first input (0:v) as the bottom layer and the video stream from the second input (1:v) as the top layer.
    • overlay=0:0:format=auto: Overlays the top video onto the bottom video starting at coordinates x=0, y=0. The format=auto option ensures proper pixel format matching and alpha blending.
    • [outv]: Labels the resulting filtered video stream.
  • -map "[outv]": Maps the processed video output to the final container.
  • -map 0:a?: Copies the audio from the base video if present.
  • -c:v libx264 -crf 18: Encodes the output video to H.264 format with high visual quality.

Positioning and Alignment Options

You can adjust the position of the transparent WebM overlay using built-in variables (W, H for background dimensions; w, h for overlay dimensions):

  • Center the overlay:

    -filter_complex "[0:v][1:v]overlay=(W-w)/2:(H-h)/2:format=auto"

  • Place in the bottom-right corner with a 20px margin:

    -filter_complex "[0:v][1:v]overlay=W-w-20:H-h-20:format=auto"

  • Stop output when the shortest input ends: Add shortest=1 to end the final video whenever either the overlay or background finishes:

    -filter_complex "[0:v][1:v]overlay=0:0:shortest=1:format=auto"

  • Delayed overlay start: Use the enable option to display the overlay only between specific timestamps (for example, starting at second 5 and ending at second 15):

    -filter_complex "[0:v][1:v]overlay=0:0:enable='between(t,5,15)':format=auto"
