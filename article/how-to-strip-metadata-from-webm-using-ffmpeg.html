How to Strip Metadata from WebM Using FFmpeg

Stripping metadata from WebM files protects user privacy, eliminates unwanted tracking information, and reduces minor file overhead. This guide explains the exact FFmpeg command-line parameters required to completely remove global metadata, stream tags, chapter markers, and encoder signatures from a WebM container without re-encoding the underlying video and audio streams.

The Basic Command

To strip standard global and chapter metadata while keeping the original audio and video streams intact, use the following command:

ffmpeg -i input.webm -map_metadata -1 -map_chapters -1 -c copy output.webm

Explanation of Parameters

  • -i input.webm: Specifies the source WebM file.
  • -map_metadata -1: Clears all global metadata, such as titles, artist names, creation dates, and custom tags.
  • -map_chapters -1: Removes all chapter markers and chapter-specific metadata from the file.
  • -c copy: Copies the audio and video streams directly without re-encoding, ensuring the process is instantaneous and causes zero quality loss.
  • output.webm: The name of the cleaned output file.

Advanced: Removing Encoder Signatures and Stream Tags

Container formats like WebM (Matroska) often automatically insert default writing application and muxing library tags (such as Lavf or Lavc). To strip stream-level metadata and prevent FFmpeg from writing its own identification headers, add bitexact flags:

ffmpeg -i input.webm -map_metadata -1 -map_chapters -1 -fflags +bitexact -flags:v +bitexact -flags:a +bitexact -c copy output.webm
  • -fflags +bitexact: Forces the muxer to not write vendor-specific identification or timestamp metadata into the container header.
  • -flags:v +bitexact and -flags:a +bitexact: Ensures no stream-specific encoder markers are injected into the video and audio bitstreams.

Verifying Metadata Removal

To confirm that all unnecessary metadata has been removed, inspect the new file using FFprobe:

ffprobe -hide_banner output.webm

If successful, the output will list only the technical stream specifications (resolution, bitrate, codec) with no additional metadata tags.
