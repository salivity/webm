How WebM Stores Embedded Color Primaries

The WebM container format, based on a subset of the Matroska (MKV) specification, defines the storage of embedded color primaries through standardized metadata elements within its Extensible Binary Meta Language (EBML) structure. By utilizing the Colour element hierarchy nested inside video track definitions, WebM allows video streams to explicitly declare their color space characteristics—such as BT.709, BT.2020, or SMPTE standards—without relying solely on the underlying video bitstream.

The EBML Structural Hierarchy

WebM organizes metadata in a tree-like EBML structure. The color primaries definition resides deep within the video track configuration:

  • Segment (0x18538067)
    • Tracks (0x1654AE6B)
      • TrackEntry (0xAE)
        • Video (0xE0)
          • Colour (0x55B0)
            • Primaries (0x55B1)

The Colour master element encapsulates all high-level color configuration parameters, including matrix coefficients, transfer characteristics, and the specific color primaries.

The Primaries Element (0x55B1)

The storage of the color primaries is handled specifically by the Primaries EBML element:

  • Element Name: Primaries
  • EBML ID: 0x55B1
  • Data Type: Unsigned Integer (uint)
  • Default Value: 2 (Unspecified)

This element defines the chromaticity coordinates of the source color primaries. Instead of storing raw CIE (x, y) coordinates for red, green, and blue within the container, WebM uses integer values that map directly to standardized color spaces defined by the ITU-T H.273 / ISO/IEC 23091-2 Coding-Independent Code Points (CICP) standard.

Standardized Primary Values

The value stored in the Primaries element corresponds to standard color spaces:

  • 1 (ITU-R BT.709): Standard gamut for HD video and sRGB content.
  • 2 (Unspecified): The default value if the element is omitted; relies on system or bitstream defaults.
  • 4 (ITU-R BT.470M): Historical NTSC system standard.
  • 5 (ITU-R BT.470BG): Historical PAL/SECAM standard.
  • 6 (SMPTE 170M): Standard definition color space.
  • 7 (SMPTE 240M): Early HDTV standard.
  • 8 (Film): Generic color film gamut (Illuminant C).
  • 9 (ITU-R BT.2020 / BT.2100): Ultra HD wide color gamut standard, commonly used for HDR.
  • 10 (SMPTE ST 428-1): DCI-P3 (CIE 1931 DCI Reference White).
  • 11 (SMPTE RP 431-2): DCI-P3 (D65 white point).
  • 12 (SMPTE EG 432-1): Display P3.
  • 22 (EBU Tech. 3213-E): JEDEC P22 phosphors.

Container vs. Bitstream Priority

WebM video codecs, such as VP8, VP9, and AV1, can also contain color primary signaling inside their individual elementary bitstream headers (e.g., Sequence Header in AV1 or Color Config in VP9).

The WebM specification mandates that the container-level Primaries element should accurately reflect the elementary stream's configuration. However, if a mismatch occurs between the container metadata (0x55B1) and the inner codec bitstream headers, decoders and rendering engines typically give precedence to the bitstream metadata, treating the WebM container metadata as fallback configuration for parsers that do not inspect the raw bitstream before initialization.
