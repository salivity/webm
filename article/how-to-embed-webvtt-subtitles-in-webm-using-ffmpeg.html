How to Embed WebVTT Subtitles in WebM Using FFmpeg

This guide explains how to mux external WebVTT (.vtt) subtitle tracks directly into a WebM (.webm) container using FFmpeg. By following the instructions below, you will combine video, audio, and subtitle streams into a single, web-compatible file without re-encoding the underlying video and audio, preserving the original quality and completing the process almost instantly.

The Basic Command

To embed a WebVTT subtitle file into a WebM video, run the following command:

ffmpeg -i input.webm -i subtitles.vtt -c:v copy -c:a copy -c:s webvtt output.webm

Command Breakdown:

  • -i input.webm: Specifies the primary input video file.
  • -i subtitles.vtt: Specifies the external WebVTT subtitle file.
  • -c:v copy: Stream-copies the video track to prevent re-encoding.
  • -c:a copy: Stream-copies the audio track to prevent re-encoding.
  • -c:s webvtt: Encodes the subtitle stream as WebVTT, which is the standard subtitle format supported by the WebM container.
  • output.webm: The output file containing the embedded subtitles.

Adding Language and Track Metadata

HTML5 players and desktop media players use metadata tags to identify subtitle tracks. You can define the language code (ISO 639-2) and a descriptive title using metadata flags:

ffmpeg -i input.webm -i subtitles.vtt -map 0:v -map 0:a -map 1:s -c:v copy -c:a copy -c:s webvtt -metadata:s:s:0 language=eng -metadata:s:s:0 title="English" output.webm
  • -map 0:v and -map 0:a: Explicitly includes the video and audio streams from the first input file (input.webm).
  • -map 1:s: Selects the subtitle stream from the second input file (subtitles.vtt).
  • -metadata:s:s:0 language=eng: Sets the language code for the first subtitle stream (s:s:0) to English (eng).
  • -metadata:s:s:0 title="English": Sets the human-readable display label for the subtitle track.

Embedding Multiple Subtitle Tracks

To include multiple language tracks in a single WebM file, add each VTT file as a separate input and map them individually:

ffmpeg -i input.webm -i english.vtt -i spanish.vtt \
-map 0:v -map 0:a -map 1:s -map 2:s \
-c:v copy -c:a copy -c:s webvtt \
-metadata:s:s:0 language=eng -metadata:s:s:0 title="English" \
-metadata:s:s:1 language=spa -metadata:s:s:1 title="Spanish" \
output.webm

Verifying the Output File

To verify that the subtitles are correctly integrated into the container, inspect the output file with FFmpeg:

ffmpeg -i output.webm

Check the output stream list. You should see an entry similar to:

Stream #0:2(eng): Subtitle: webvtt (default)
    Metadata:
      title           : English
      language        : eng
