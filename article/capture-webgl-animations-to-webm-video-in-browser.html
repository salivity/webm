Capture WebGL Animations to WebM Video in Browser

Capturing WebGL animations directly into a WebM video file can be accomplished entirely on the client side using native browser APIs. By combining the HTMLCanvasElement.captureStream() method with the MediaRecorder API, you can record the rendered frames of a WebGL canvas in real time or fixed-rate intervals, encode them into the WebM format, and export the result as a downloadable video blob without relying on server-side rendering pipelines.

Step 1: Capture the Canvas Stream

The captureStream() method extracts a real-time MediaStream directly from an HTML <canvas> element rendering WebGL. You can pass a target frame rate (FPS) as an argument.

const canvas = document.querySelector('canvas');
const fps = 60;
const stream = canvas.captureStream(fps);

If your WebGL context clears the frame buffer automatically between frames, ensure you create your WebGL context with preserveDrawingBuffer: true if you experience flickering or blank frames, though modern implementations of captureStream() typically read from the composited canvas directly.

Step 2: Set Up MediaRecorder

Initialize the MediaRecorder instance using the canvas stream. Specify the WebM MIME type to ensure client-side encoding.

const options = {
  mimeType: 'video/webm; codecs=vp9',
  videoBitsPerSecond: 5000000 // 5 Mbps for higher quality
};

// Fallback to default WebM if VP9 is unsupported
const mimeType = MediaRecorder.isTypeSupported(options.mimeType) 
  ? options.mimeType 
  : 'video/webm';

const mediaRecorder = new MediaRecorder(stream, { mimeType, videoBitsPerSecond: options.videoBitsPerSecond });

Step 3: Collect and Assemble Video Data

Set up event listeners to store recorded video chunks as they become available, and convert those chunks into a downloadable Blob when recording stops.

const recordedChunks = [];

mediaRecorder.ondataavailable = (event) => {
  if (event.data && event.data.size > 0) {
    recordedChunks.push(event.data);
  }
};

mediaRecorder.onstop = () => {
  const blob = new Blob(recordedChunks, { type: 'video/webm' });
  const url = URL.createObjectURL(blob);
  
  // Create download link
  const a = document.createElement('a');
  a.href = url;
  a.download = 'webgl-animation.webm';
  document.body.appendChild(a);
  a.click();
  
  // Cleanup
  setTimeout(() => {
    document.body.removeChild(a);
    URL.revokeObjectURL(url);
  }, 100);
};

Step 4: Control the Recording Lifecycle

Start and stop the recording process programmatically to capture the desired duration of the animation.

// Start recording
mediaRecorder.start();

// Stop recording after 5 seconds
setTimeout(() => {
  if (mediaRecorder.state !== 'inactive') {
    mediaRecorder.stop();
  }
}, 5000);

Deterministic Frame Capture (Alternative for Heavy Scenes)

If the WebGL animation is computationally heavy, recording in real time may drop frames. To guarantee consistent quality, capture frames deterministically:

  1. Pass 0 to captureStream(0) to prevent automatic frame capture.
  2. Render each animation step manually.
  3. Call stream.getVideoTracks()[0].requestFrame() immediately after rendering each frame.

This ensures every frame is encoded into the final WebM file without stuttering, regardless of how long each frame takes to render.
