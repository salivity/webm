Capture HTML5 Canvas to WebM Using MediaRecorder

Recording an HTML5 <canvas> element and exporting it as a WebM video is achieved by combining the captureStream() method with the MediaRecorder API. The canvas generates a live video stream from its rendered visual output, which the MediaRecorder receives, encodes frame-by-frame into the WebM container format (typically using VP8 or VP9 codecs), and bundles into chunks for playback or download.

1. Extracting the Stream with captureStream()

The process begins on the canvas element itself using the HTMLCanvasElement.captureStream() method. This method continuously monitors the canvas context for updates and outputs a standard MediaStream object.

const canvas = document.getElementById('myCanvas');
const fps = 30; // Frames per second
const stream = canvas.captureStream(fps);

You can pass an optional frame rate parameter. If omitted, the stream captures a new frame whenever the canvas changes or when explicitly triggered.

2. Initializing MediaRecorder

Once the MediaStream is created, it is passed directly into a new MediaRecorder instance. You must configure the recording options to use the WebM format.

const options = { mimeType: 'video/webm; codecs=vp9' };
const mediaRecorder = new MediaRecorder(stream, options);

Common supported MIME types include:

  • video/webm
  • video/webm; codecs=vp8
  • video/webm; codecs=vp9

3. Collecting Video Data Chunks

The MediaRecorder operates asynchronously and fires a dataavailable event whenever a segment of encoded video data is ready. You collect these chunks in an array.

const recordedChunks = [];

mediaRecorder.ondataavailable = (event) => {
  if (event.data.size > 0) {
    recordedChunks.push(event.data);
  }
};

4. Finalizing and Exporting the WebM File

When you call mediaRecorder.stop(), the recording completes and triggers the stop event. Inside this event listener, combine the recorded chunks into a single Blob of type video/webm.

mediaRecorder.onstop = () => {
  const blob = new Blob(recordedChunks, { type: 'video/webm' });
  const videoUrl = URL.createObjectURL(blob);
  
  // Create a download link or assign to a <video> element
  const a = document.createElement('a');
  a.href = videoUrl;
  a.download = 'canvas-recording.webm';
  a.click();
};

// Start and stop controls
mediaRecorder.start();
// Run your canvas animations here...
// mediaRecorder.stop();

This sequence handles the pipeline entirely on the client side: drawing graphics on the canvas, streaming frames into the recorder, encoding them in real time, and outputting a complete WebM video file.
