Libvpx Constrained Quality WebM Encoding

Constrained-Quality (CQ) mode in WebM (VP8 and VP9) allows an encoder to adaptively lower the bitrate for simple scenes while maintaining a maximum quality ceiling and an upper bitrate limit. This article outlines the specific configuration struct parameters and control identifiers in the libvpx C API required to enable and tune constrained-quality encoding.

1. Rate Control Mode (rc_end_usage)

To activate Constrained-Quality mode, you must configure the rc_end_usage field within the vpx_codec_enc_cfg_t configuration structure. Set this value to VPX_CQ:

vpx_codec_enc_cfg_t cfg;
vpx_codec_enc_config_default(vpx_codec_vp9_cx(), &cfg, 0);

cfg.rc_end_usage = VPX_CQ;

When set to VPX_CQ, the encoder targets a specific visual quality level but restricts the stream so it does not exceed the designated target bitrate.

2. CQ Target Level (VP8E_SET_CQ_LEVEL)

The actual quality target is set using the vpx_codec_control() function with the VP8E_SET_CQ_LEVEL control ID. This parameter accepts an integer corresponding to the quantizer scale (ranging from 0 to 63):

vpx_codec_control(&codec_ctx, VP8E_SET_CQ_LEVEL, cq_level_value);
  • Lower values produce higher visual quality and larger file sizes.
  • Higher values produce lower quality and smaller file sizes.
  • Typical values range between 15 and 35, depending on the visual fidelity requirements.

3. Bitrate Limit (rc_target_bitrate)

In CQ mode, the rc_target_bitrate parameter in vpx_codec_enc_cfg_t acts as an upper boundary rather than an absolute target. The encoder will attempt to deliver the quality set by VP8E_SET_CQ_LEVEL unless doing so requires a bitrate exceeding this value:

cfg.rc_target_bitrate = 2000; // Value defined in kilobits per second (kbps)

If complex scene motion causes the stream to surpass this bandwidth threshold, the encoder temporarily increases quantization (lowering quality) to respect the bitrate constraint.

4. Quantizer Boundaries (rc_min_quantizer and rc_max_quantizer)

To guarantee the quantizer remains within an acceptable operational range, configure rc_min_quantizer and rc_max_quantizer in vpx_codec_enc_cfg_t:

cfg.rc_min_quantizer = 0;   // Lowest permissible quantizer (highest quality)
cfg.rc_max_quantizer = 63;  // Highest permissible quantizer (lowest quality)

Setting these limits prevents the encoder from dropping quality below acceptable visual tolerances during high-action sequences or wasting bits on static frames.
