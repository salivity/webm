Add Transparent WebM Alerts to OBS Browser Source

Transparent WebM video files are the industry standard for stream overlays and animated alerts because they retain alpha channel transparency while keeping file sizes small. In OBS Studio, these alerts can be rendered seamlessly through a Browser Source, either by pointing to a web-based alert platform or by serving a local HTML page that embeds the video. This guide covers how to set up a Browser Source for local or hosted transparent WebM files, the necessary HTML configuration, and essential settings to ensure smooth playback.

Method 1: Using an Alert Service URL

If your transparent WebM is hosted on an alert service like Streamlabs, StreamElements, or Botrix, the platform automatically renders the video inside its web layer.

  1. Open OBS Studio.
  2. Under the Sources dock, click the + (Add) icon and select Browser.
  3. Name the source (e.g., "WebM Alert Box") and click OK.
  4. In the URL field, paste your alert box widget URL.
  5. Set the Width and Height to match your canvas resolution (e.g., 1920x1080) or the specific dimensions of your alert layout.
  6. Click OK to save.

Method 2: Loading a Local Transparent WebM File

OBS Studio's Browser Source uses the Chromium Embedded Framework (CEF), which natively supports transparent WebM (VP8 or VP9 with alpha channel). The most reliable way to display and control a local WebM alert is by wrapping it in a basic HTML file.

1. Create the HTML Wrapper

Create a file named alert.html in the same folder as your WebM file (e.g., alert.webm) with the following code:

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <style>
        body {
            margin: 0;
            padding: 0;
            background-color: rgba(0, 0, 0, 0);
            overflow: hidden;
            display: flex;
            justify-content: center;
            align-items: center;
            height: 100vh;
        }
        video {
            background: transparent;
            width: 100%;
            height: 100%;
            object-fit: contain;
        }
    </style>
</head>
<body>
    <video autoplay loop muted playsinline>
        <source src="alert.webm" type="video/webm">
    </video>
</body>
</html>

Note: Remove the loop attribute if the alert should only play once per trigger via JavaScript.

2. Add the HTML to OBS Studio

  1. In OBS Studio, click the + icon under Sources and choose Browser.
  2. Name the source and click OK.
  3. Check the Local file checkbox.
  4. Click Browse and select your alert.html file.
  5. Set the Width and Height to match your video or canvas dimensions.
  6. Check Refresh browser when scene becomes active if you want the animation to restart every time you switch to the scene.
  7. Click OK.

Essential OBS Browser Source Settings

  • Custom CSS: Clear any default CSS inside the browser source properties to avoid unwanted background colors. Ensure body { background-color: rgba(0, 0, 0, 0); margin: 0px auto; overflow: hidden; } is present if not using an external stylesheet.
  • Hardware Acceleration: If the WebM video stutters or drops frames, navigate to Settings > Advanced in OBS Studio, check Enable Browser Source Hardware Acceleration, and restart OBS.
  • Audio Monitoring: If your WebM file contains audio, check Control audio via OBS in the Browser Source properties to route and mix the alert audio directly in the OBS Audio Mixer.
