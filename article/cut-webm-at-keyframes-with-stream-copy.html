Cut WebM at Keyframes with Stream Copy

Cutting a WebM video at exact keyframe boundaries using stream copying allows you to trim video segments instantly without re-encoding, preserving 100% of the original video and audio quality. Because stream copying cannot split compressed data between keyframes (I-frames), identifying the exact timestamps of keyframes beforehand is required to achieve precise cuts without visual artifacts or dropped frames.

Step 1: Find Keyframe Timestamps Using FFprobe

Before cutting, you must locate the exact timestamps where keyframes exist in your WebM file. Run the following ffprobe command to list all keyframes with their respective presentation timestamps:

ffprobe -select_streams v -show_frames -show_entries frame=pkt_pts_time,key_frame -of csv=p=0 input.webm | grep ",1"

This outputs a list of timestamps (in seconds) corresponding strictly to keyframes (e.g., 0.000000,1, 4.240000,1, 9.560000,1). Choose your desired start and end points directly from these generated timestamps.

Step 2: Cut the Video with FFmpeg Stream Copying

Once you have identified your starting keyframe timestamp (e.g., 4.240) and your ending keyframe timestamp (e.g., 9.560), execute the cut using FFmpeg:

ffmpeg -ss 4.240 -to 9.560 -i input.webm -c copy output.webm
  • -ss 4.240: Specifies the start time. When placed before -i, FFmpeg seeks directly to the specified keyframe.
  • -to 9.560: Specifies the end time relative to the original file timeline.
  • -i input.webm: Designates the source file.
  • -c copy: Enables stream copying mode, bypassing decoding and encoding processes entirely.

Step 3: Verify the Output File

Ensure the cut video starts smoothly and contains no missing frames or audio desynchronization by inspecting the stream properties of the output:

ffprobe -v error -show_entries format=duration -of default=noprint_wrappers=1:nokey=1 output.webm

The resulting WebM segment will be cleanly split at the exact frames selected, maintaining original VP8/VP9 and Vorbis/Opus stream integrity without generational loss.
