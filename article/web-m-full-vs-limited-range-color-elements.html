WebM Full vs Limited Range Color Elements

WebM video files use specific Matroska-derived EBML elements nested inside the track definitions to distinguish between full-range and limited-range color. By signaling this metadata in the container, media players and decoders can properly map luminance and chrominance values to display panels without relying solely on the underlying video bitstream.

The color range configuration resides within the video track hierarchy of the WebM container. To identify the color range, decoders inspect the following element path:

Segment > Tracks > TrackEntry > Video > Colour > Range

The Primary Element: Range

The definitive container element is Range (EBML ID: 0x55B9), which is a child of the Colour master element (EBML ID: 0x55B0).

The Range element is an unsigned integer that specifies the clipping of color coordinates. It accepts the following values:

  • 0 (Unspecified): The color range is not explicitly declared at the container level.
  • 1 (Broadcast Range / Limited Range): Indicates standard limited-range video. For standard 8-bit YUV content, luma (Y) is mapped from 16 to 235, and chroma (Cb/Cr) is mapped from 16 to 240.
  • 2 (Full Range): Indicates full-range PC levels. For 8-bit content, all channels (Y, Cb, Cr, or R, G, B) span the complete 0 to 255 spectrum.
  • 3 (Matrix/Transfer Defined): Range is implicitly defined by the associated MatrixCoefficients or TransferCharacteristics elements.

Complementary Elements in the Colour Master

While Range directly controls the range limits, it operates alongside several sibling elements under the Colour master element to ensure accurate rendering:

  • MatrixCoefficients (0x55B1): Defines the color space transform matrix (e.g., BT.709, BT.2020).
  • BitsPerChannel (0x55B2): Sets the bit depth (e.g., 8-bit, 10-bit), which defines the scale of the full or limited ranges.
  • TransferCharacteristics (0x55B5): Denotes the opto-electronic transfer function (e.g., BT.709, SMPTE ST 2084/PQ, HLG).

Default Behavior and Codec Bitstream Fallback

If the Colour master element or the Range sub-element is missing from the WebM header, the container treats the range as unspecified (0). In such cases, decoders will typically read the color range flags from the elementary video bitstream itself—such as the color_range bit in VP9 sequence headers or AV1 sequence header OBU syntax. If absent from both the container and the bitstream, decoders commonly default to limited range (1) for YUV formats and full range (2) for RGB formats.
