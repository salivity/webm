Verify WebM Alpha Channel Using FFprobe

This guide explains how to use FFprobe, a versatile multimedia stream analyzer bundled with FFmpeg, to verify whether a WebM video file contains a valid transparency (alpha) channel. By querying the video stream's pixel format and metadata properties, you can immediately determine if the file includes alpha data without needing to open it in a video editing suite or web browser.

Inspect the Pixel Format

The most direct way to check for an alpha channel is to query the pixel format (pix_fmt) of the video stream. Video files with transparency typically use formats with an "a" designator, such as yuva420p or yuva444p.

Run the following command in your terminal:

ffprobe -v error -select_streams v:0 -show_entries stream=pix_fmt -of default=noprint_wrappers=1:nokey=1 input.webm

Interpreting the Output:

  • yuva420p (or similar containing yuva): The file has a designated alpha channel integrated into its pixel format.
  • yuv420p (or standard yuv without a): The video stream does not use a transparent pixel format.

Check for VP8/VP9 Alpha Metadata

Certain WebM encoders store alpha channel information as side data or metadata properties rather than declaring a yuva pixel format at the top level. To check for this metadata, query the stream's alpha properties:

ffprobe -v error -select_streams v:0 -show_entries stream=alpha_mode -of default=noprint_wrappers=1 input.webm

Alternatively, inspect all stream details to search for alpha tags:

ffprobe -v error -select_streams v:0 -show_entries stream_tags:stream -of json input.webm

Interpreting the Output:

  • alpha_mode=1: Indicates that a dedicated alpha channel layer is embedded in the VP8 or VP9 stream.
  • alpha_mode=0 (or absent): No alpha layer metadata is present.

Summary Checklist

A WebM file has a valid alpha channel if either of the following conditions is met:

  1. The pix_fmt output contains an a (e.g., yuva420p).
  2. The alpha_mode stream entry is explicitly set to 1.
