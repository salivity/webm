Adjust videoBitsPerSecond in WebM MediaRecorder

Adjusting the videoBitsPerSecond constraint in a WebM MediaRecorder instance allows developers to control video quality and output file size during media capture in JavaScript. This guide covers how to properly define the bitrate within the constructor's options object, the hierarchy between general and specific bitrate settings, and best practices for browser compatibility.

Setting videoBitsPerSecond in the Constructor

The MediaRecorder interface accepts an optional configuration object as its second argument. To set the video bitrate specifically for WebM video, define both the mimeType and the videoBitsPerSecond properties within this object.

// Obtain the media stream (e.g., from camera or screen capture)
const stream = await navigator.mediaDevices.getUserMedia({ video: true, audio: true });

// Define the recording options
const options = {
  mimeType: 'video/webm;codecs=vp9', // or 'video/webm;codecs=vp8'
  videoBitsPerSecond: 2500000 // 2.5 Mbps
};

// Initialize MediaRecorder with the specified bitrate
const mediaRecorder = new MediaRecorder(stream, options);

Bitrate Settings Hierarchy

The MediaRecorder API provides three properties to manage bitrates:

  • videoBitsPerSecond: Controls only the video track bitrate.
  • audioBitsPerSecond: Controls only the audio track bitrate.
  • bitsPerSecond: Sets an overall target bitrate shared between audio and video.

If you specify videoBitsPerSecond, it overrides any value set in bitsPerSecond for the video track. For example:

const options = {
  mimeType: 'video/webm',
  bitsPerSecond: 1000000,        // Fallback overall bitrate (1 Mbps)
  videoBitsPerSecond: 3000000,   // Explicitly allocates 3 Mbps to video
  audioBitsPerSecond: 128000     // Explicitly allocates 128 kbps to audio
};

const mediaRecorder = new MediaRecorder(stream, options);

Checking Support and Inspecting Runtime Values

Bitrates are treated as targets rather than strict limits. The browser's underlying encoder adapts the actual bitrate depending on hardware capabilities, network conditions, and the complexity of the video stream.

Before initializing, ensure the requested MIME type is supported:

const mimeType = 'video/webm;codecs=vp8';

if (MediaRecorder.isTypeSupported(mimeType)) {
  const mediaRecorder = new MediaRecorder(stream, {
    mimeType: mimeType,
    videoBitsPerSecond: 1500000
  });

  // Verify the assigned bitrate
  console.log('Target Video Bitrate:', mediaRecorder.videoBitsPerSecond);
} else {
  console.error('The specified WebM MIME type is not supported.');
}

Once initialized, the mediaRecorder.videoBitsPerSecond read-only property reflects the configured target rate used by the encoder.
