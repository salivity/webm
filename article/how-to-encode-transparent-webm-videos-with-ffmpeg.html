How to Encode Transparent WebM Videos with FFmpeg

Encoding a video with a transparent background into the WebM format using FFmpeg requires utilizing a codec that supports an alpha channel, specifically VP8 or VP9, alongside a compatible pixel format such as yuva420p. This guide explains the necessary FFmpeg commands, core parameters, and best practices for converting transparent source files—such as ProRes 4444 MOV files or PNG sequences—into lightweight, web-ready transparent WebM videos.

Key Requirements for Transparent WebM

WebM supports transparency (alpha channel) through the VP8 (libvpx) and VP9 (libvpx-vp9) video codecs. To preserve transparency during encoding:

  1. Source Asset: The input must contain an alpha channel (e.g., Apple ProRes 4444, QuickTime Animation, or a PNG sequence).
  2. Codec Selection: Use libvpx-vp9 (recommended for better compression) or libvpx (VP8).
  3. Pixel Format: Set the pixel format to an alpha-enabled format, typically yuva420p.

Encoding with VP9 (Recommended)

VP9 offers superior compression and quality compared to VP8. To encode a transparent video using VP9, run the following command:

ffmpeg -i input.mov -c:v libvpx-vp9 -pix_fmt yuva420p -b:v 0 -crf 30 output.webm

Parameter Breakdown:

  • -i input.mov: Specifies the input file with an existing alpha channel.
  • -c:v libvpx-vp9: Sets the video codec to VP9.
  • -pix_fmt yuva420p: Ensures the output includes an alpha channel (yuva stands for YUV + Alpha).
  • -b:v 0 -crf 30: Enables Constant Quality mode. The -crf value can range from 0 to 63, with lower values yielding higher quality (values between 20 and 35 are standard).

Note: In some specific FFmpeg builds, adding -auto-alt-ref 0 is required for VP9 to prevent issues with alpha channel rendering.

Encoding with VP8 (Legacy)

If you need compatibility with older browsers or systems that do not fully support VP9 alpha channels, you can use VP8:

ffmpeg -i input.mov -c:v libvpx -pix_fmt yuva420p -b:v 2M output.webm

Parameter Breakdown:

  • -c:v libvpx: Uses the standard VP8 encoder.
  • -b:v 2M: Sets a target bitrate (e.g., 2 Megabits per second).

Converting an Image Sequence (PNG) to Transparent WebM

To encode a series of transparent PNG images into a WebM video at 30 frames per second:

ffmpeg -framerate 30 -i frame_%04d.png -c:v libvpx-vp9 -pix_fmt yuva420p output.webm
  • -framerate 30: Sets the frame rate to 30 FPS.
  • frame_%04d.png: Matches sequences like frame_0001.png, frame_0002.png, etc.

Verifying Transparency

To check if the exported file has preserved its alpha channel, inspect the stream details using FFprobe:

ffprobe -v error -select_streams v:0 -show_entries stream=pix_fmt output.webm

If the returned pix_fmt is yuva420p or another format containing the letter a, the alpha channel is present.
