Forced Subtitle Attributes in WebM Explained

WebM relies on a strict subset of the Matroska (EBML) specification to define multimedia streams, utilizing specific track-level header flags to dictate how subtitles behave during playback. To handle forced subtitles—tracks designed to display essential narrative translations even when regular captions are disabled—WebM utilizes the FlagForced element in conjunction with FlagDefault within the track configuration.

The Primary Attribute: FlagForced

The core container attribute responsible for marking a subtitle track as forced is FlagForced.

  • EBML Element Name: FlagForced
  • EBML ID: [55][AA]
  • Type: Unsigned Integer (Boolean: 0 or 1)
  • Default Value: 0 (False)

When set to 1, this element marks the subtitle track as containing information essential to the narrative that must be displayed, regardless of whether the user has globally disabled subtitles. Typical use cases include translating short segments of foreign dialogue, translating alien languages, or displaying translated signage while the main audio remains in the viewer’s native language.

Supporting Attribute: FlagDefault

While FlagForced identifies the nature of the content, media players frequently rely on FlagDefault to handle automatic stream selection.

  • EBML Element Name: FlagDefault
  • EBML ID: [88]
  • Type: Unsigned Integer (Boolean: 0 or 1)
  • Default Value: 1 (True, if omitted in standard Matroska specifications)

For forced subtitles to activate predictably across various software environments, FlagDefault should be set to 1 on the forced subtitle track. This informs the playback engine that the track is eligible for immediate activation if no explicit user preference overrides it.

Required Parent and Contextual Elements

For a WebM player to properly parse and render a forced subtitle stream, the flags must reside inside the proper track definition structure:

  1. Tracks ([16][54][AE][6B]): The top-level master element containing all stream definitions.
  2. TrackEntry ([AE]): The master element representing the specific subtitle track.
    • TrackType ([83]): Must be set to 17 (hexadecimal 0x11), which identifies the track as a subtitles stream.
    • CodecID ([86]): WebM exclusively supports WebVTT for subtitles, represented as D_WEBVTT/SUBTITLES or D_WEBVTT/METADATA.
    • Language ([22][B5][9C]): Defines the language tag (ISO 639-2 or BCP 47) so players can match the forced track to the active audio language.
    • FlagForced ([55][AA]): Set to 1.
    • FlagDefault ([88]): Set to 1.

Player Behavior and Compatibility

Unlike standard desktop media players (such as MPV or VLC) which read the Matroska FlagForced binary attribute natively, HTML5 browsers parsing WebM via native <video> elements often rely on HTML-level attributes rather than container-level EBML flags.

When embedding WebM in web browsers, developers typically map the container's FlagForced state to the HTML <track> element using kind="subtitles" and the default boolean attribute to ensure consistent forced behavior across client platforms.
