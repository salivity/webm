VP8 Intra Prediction Modes in WebM Explained

In VP8-encoded WebM video, intra-frame prediction exploits spatial redundancy by predicting the pixel values of a macroblock using previously decoded neighboring pixels from the same frame. For intra-coded macroblocks, VP8 provides distinct prediction modes categorized by block size and color plane: four modes for 16x16 luma blocks, ten directional modes for 4x4 luma sub-blocks, and four modes for 8x8 chroma blocks.

16x16 Luma Intra-Prediction Modes

When a 16x16 luma macroblock is uniform or lacks high-frequency detail, VP8 predicts the entire 16x16 area using one of four modes:

  • DC Prediction (DC_PRED): Predicts all pixels in the 16x16 block using the single average value of the pixels in the row directly above and the column directly to the left.
  • Vertical Prediction (V_PRED): Replicates the row of pixels directly above the macroblock vertically down across all rows.
  • Horizontal Prediction (H_PRED): Replicates the column of pixels directly to the left of the macroblock horizontally across all columns.
  • TrueMotion Prediction (TM_PRED): A proprietary mode that predicts pixel values based on the left and above pixels, adjusted by the top-left neighbor pixel value using the formula Predicted = Left + Above - TopLeft.

4x4 Luma Intra-Prediction Modes

For complex scenes with fine textures and edges, a 16x16 macroblock can be divided into sixteen 4x4 sub-blocks. Each 4x4 sub-block is predicted individually in raster scan order using one of ten available modes:

  • B_DC_PRED (DC): Predicts all pixels from the average of the neighboring boundary pixels.
  • B_TM_PRED (TrueMotion): Extrapolates gradients using the top, left, and top-left neighbor pixels.
  • B_VE_PRED (Vertical): Extrapolates pixels vertically from the above row.
  • B_HE_PRED (Horizontal): Extrapolates pixels horizontally from the left column.
  • B_LD_PRED (Left-Down Diagonal): Interpolates pixels along a diagonal pointing down and to the left (approx. 45 degrees).
  • B_RD_PRED (Right-Down Diagonal): Interpolates pixels along a diagonal pointing down and to the right (approx. 45 degrees).
  • B_VR_PRED (Vertical-Right): Interpolates pixels along a directional vector tilted slightly to the right of the vertical axis (approx. 27 degrees from vertical).
  • B_VL_PRED (Vertical-Left): Interpolates pixels along a directional vector tilted slightly to the left of the vertical axis (approx. 27 degrees from vertical).
  • B_HD_PRED (Horizontal-Down): Interpolates pixels along a directional vector tilted slightly downward from the horizontal axis (approx. 27 degrees from horizontal).
  • B_HU_PRED (Horizontal-Up): Interpolates pixels along a directional vector tilted slightly upward from the horizontal axis (approx. 27 degrees from horizontal).

8x8 Chroma Intra-Prediction Modes

The chroma components (U and V planes) are subsampled at 8x8 pixels per macroblock in standard 4:2:0 format. Chroma intra-prediction is applied independently to both U and V planes using the same four baseline modes found in 16x16 luma prediction:

  • DC Prediction (DC_PRED): Fills the 8x8 chroma block with the average of adjacent top and left chroma pixels.
  • Vertical Prediction (V_PRED): Copies the 8 pixels directly above into every row below.
  • Horizontal Prediction (H_PRED): Copies the 8 pixels directly to the left across every column.
  • TrueMotion Prediction (TM_PRED): Applies the Left + Above - TopLeft gradient algorithm across the 8x8 block.
