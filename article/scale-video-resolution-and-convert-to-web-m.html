Scale Video Resolution and Convert to WebM

This guide provides a straightforward tutorial on using the FFmpeg command-line interface to scale video resolution and convert video files to the WebM format. You will learn the standard command syntax, how to automatically maintain aspect ratios during resizing, and the key encoding parameters required for high-quality WebM output.

The Basic Command

To scale a video to a specific resolution (such as 1280x720) and convert it to WebM using the modern VP9 codec, run the following FFmpeg command:

ffmpeg -i input.mp4 -vf scale=1280:720 -c:v libvpx-vp9 -b:v 0 -crf 30 -c:a libopus output.webm

Command Breakdown

  • -i input.mp4: Specifies the path to the source video file.
  • -vf scale=1280:720: Applies the video filter (-vf) to scale the output to a width of 1280 pixels and a height of 720 pixels.
  • -c:v libvpx-vp9: Sets the video codec to VP9, the standard high-efficiency codec for WebM.
  • -crf 30: Sets the Constant Rate Factor for quality control. Values for VP9 typically range from 0 to 63, where lower numbers mean higher quality (values between 25 and 35 are recommended for general use).
  • -b:v 0: Disables the fixed bitrate to allow CRF mode to manage the video quality variable bitrate dynamically.
  • -c:a libopus: Sets the audio codec to Opus, the standard companion audio format for WebM containers.
  • output.webm: Defines the name and extension of the final output file.

Maintaining the Aspect Ratio

To prevent distortion, you can scale one dimension and let FFmpeg automatically calculate the other dimension based on the original aspect ratio:

Set Specific Width (Automatic Height)

ffmpeg -i input.mp4 -vf scale=1920:-2 -c:v libvpx-vp9 -b:v 0 -crf 30 -c:a libopus output.webm

Using -2 instead of -1 ensures that the calculated dimension is divisible by 2, which is required by most video codecs.

Set Specific Height (Automatic Width)

ffmpeg -i input.mp4 -vf scale=-2:1080 -c:v libvpx-vp9 -b:v 0 -crf 30 -c:a libopus output.webm

Scale by Percentage

To reduce the video resolution by half (50%):

ffmpeg -i input.mp4 -vf scale=iw/2:ih/2 -c:v libvpx-vp9 -b:v 0 -crf 30 -c:a libopus output.webm

Legacy VP8 Encoding

If you need compatibility with older browsers or systems that do not support VP9, use the older libvpx (VP8) codec and libvorbis for audio:

ffmpeg -i input.mp4 -vf scale=1280:720 -c:v libvpx -b:v 1M -c:a libvorbis output.webm
