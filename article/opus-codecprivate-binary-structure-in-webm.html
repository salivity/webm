Opus CodecPrivate Binary Structure in WebM

In WebM containers using the A_OPUS Codec ID, the CodecPrivate element contains the standard Opus identification header, designated as OpusHead. This binary data provides decoders with essential initialization parameters—including the channel count, pre-skip delay, original input sample rate, output gain, and channel mapping rules—before any audio frames are processed.

The OpusHead Specification

The WebM specification mandates that the CodecPrivate element encapsulates the exact identification header format specified in Section 5.1 of RFC 7845 (Ogg Opus). All multi-byte numeric fields are stored in little-endian byte order.

The header has a minimum length of 19 bytes for family 0 (mono or stereo) and expands if multi-channel surround mapping is used.

Byte Layout Table

Byte Offset Size (Bytes) Field Name Data Type Description
0 8 Magic Signature ASCII String Fixed string: OpusHead (0x4F 0x70 0x75 0x73 0x48 0x65 0x61 0x64)
8 1 Version uint8 Version number; must be 0x01
9 1 Output Channel Count uint8 Number of output channels (1 to 255)
10 2 Pre-skip uint16 (LE) Number of samples at 48 kHz to discard from the beginning
12 4 Input Sample Rate uint32 (LE) Informational sampling rate of original input (e.g., 48000 Hz)
14 2 Output Gain int16 (LE) Additional gain in \(dB\) (\(Q7.8\) fixed-point format). 0x0000 is 0 dB
16 1 Channel Mapping Family uint8 0x00 (mono/stereo), 0x01 (Vorbis mapping), or 0xFE/0xFF

Channel Mapping Extension (Family > 0)

When the Channel Mapping Family byte (offset 16) is set to any value greater than 0, additional bytes immediately follow to define stream counts and surround speaker routing:

Offset Size (Bytes) Field Name Data Type Description
17 1 Stream Count (\(N\)) uint8 Total number of Opus streams encoded in each packet
18 1 Coupled Stream Count (\(M\)) uint8 Number of paired (stereo) streams (\(M \le N\))
19 \(C\) Channel Mapping uint8 array Array of \(C\) bytes (where \(C\) is Channel Count), mapping output channels to stream streams

If the mapping family is 0, these extra bytes are omitted, and the total size remains exactly 19 bytes.

Example: Standard Stereo Configuration (Family 0)

A common stereo configuration recorded at 48,000 Hz, with a typical 312-sample pre-skip (6.5 ms) and 0 dB gain, yields a 19-byte hexadecimal sequence:

  • Magic Signature: 4F 70 75 73 48 65 61 64 ("OpusHead")
  • Version: 01 (Version 1)
  • Channels: 02 (2 channels)
  • Pre-skip: 38 01 (312 in little-endian)
  • Sample Rate: 80 BB 00 00 (48000 in little-endian)
  • Gain: 00 00 (0 dB)
  • Mapping Family: 00 (Direct mono/stereo mapping)

Complete hex representation in CodecPrivate:

4F 70 75 73 48 65 61 64 01 02 38 01 80 BB 00 00 00 00 00
