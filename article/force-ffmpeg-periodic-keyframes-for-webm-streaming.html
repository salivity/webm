Force FFmpeg Periodic Keyframes for WebM Streaming

This article explains how to configure FFmpeg command-line flags to force periodic keyframes in WebM video streams. Setting regular keyframe intervals (Group of Pictures or GOP size) is essential for smooth WebM playback, enabling predictable segment boundaries for adaptive streaming protocols like DASH, faster seeking, and consistent buffering behavior.

Essential Flags for Periodic Keyframes

To enforce regular keyframes in WebM files encoded with libvpx or libvpx-vp9, use a combination of standard GOP flags and forced keyframe expressions.

1. Time-Based Keyframe Insertion: -force_key_frames

The most reliable method for streaming is forcing keyframes at exact time intervals, regardless of the source video's frame rate:

-force_key_frames "expr:gte(t,n_forced*2)"
  • t: Current presentation timestamp in seconds.
  • n_forced: The number of forced keyframes generated so far.
  • 2: Forces an intra-frame (keyframe) every 2 seconds. Adjust this integer to your desired segment duration.

2. Frame-Based Keyframe Control: -g and -keyint_min

You can also force keyframes by locking the GOP size to a specific number of frames:

-g 60 -keyint_min 60
  • -g <frames>: Sets the maximum distance between keyframes. For example, if your video runs at 30 fps, setting -g 60 targets a keyframe every 2 seconds.
  • -keyint_min <frames>: Sets the minimum distance between keyframes. Setting -keyint_min equal to -g prevents the encoder from inserting extra keyframes during sudden scene changes, maintaining a strictly regular interval.

3. Scene Change Detection: -sc_threshold 0

By default, VP8 and VP9 encoders insert keyframes when a scene change is detected. To maintain a purely periodic interval and prevent irregular keyframe distribution, disable dynamic scene detection:

-sc_threshold 0

Complete Command Examples

Standard Periodic Keyframes Using Time Intervals (Recommended)

This command transcodes an input file to a WebM (VP9/Opus) stream with a guaranteed keyframe every 2 seconds:

ffmpeg -i input.mp4 \
  -c:v libvpx-vp9 -b:v 2M \
  -force_key_frames "expr:gte(t,n_forced*2)" \
  -c:a libopus -b:a 128k \
  output.webm

Fixed Frame-Count Interval for Fixed Frame Rate (30 FPS Source)

This command locks the GOP to exactly 60 frames (a keyframe every 2 seconds at 30 fps) while disabling scene change overrides:

ffmpeg -i input.mp4 \
  -c:v libvpx-vp9 -b:v 2M \
  -g 60 -keyint_min 60 -sc_threshold 0 \
  -c:a libopus -b:a 128k \
  output.webm

Verification

To verify that keyframes appear at the intended intervals, run ffprobe to inspect frame types and timestamps:

ffprobe -select_streams v -show_frames \
  -show_entries frame=pkt_pts_time,pict_type \
  output.webm | grep -B 1 "pict_type=I"

This outputs only the intra-frames (pict_type=I) and their timestamps (pkt_pts_time), allowing you to confirm that the keyframes are placed consistently.
