Batch Convert MP4 to WebM with FFmpeg

This guide explains how to batch convert an entire directory of MP4 videos into web-optimized WebM files using the free, open-source command-line tool FFmpeg. By using simple loop commands in your terminal or command prompt, you can automate the encoding process for all files at once using modern VP9 video and Opus audio codecs for optimal compression and web streaming.

Prerequisites

Ensure that you have FFmpeg installed and accessible in your system's PATH. Open your terminal or command prompt and navigate to the directory containing your .mp4 files using the cd command before running any of the following commands.

Linux and macOS (Bash / Zsh)

Run the following shell loop in your terminal:

for f in *.mp4; do
  ffmpeg -i "$f" -c:v libvpx-vp9 -crf 30 -b:v 0 -c:a libopus -b:a 128k "${f%.mp4}.webm"
done

Windows (PowerShell)

Run the following command in PowerShell:

Get-ChildItem *.mp4 | ForEach-Object {
    ffmpeg -i $_.FullName -c:v libvpx-vp9 -crf 30 -b:v 0 -c:a libopus -b:a 128k "$($_.BaseName).webm"
}

Windows (Command Prompt)

Run the following single-line command directly in CMD:

for %i in (*.mp4) do ffmpeg -i "%i" -c:v libvpx-vp9 -crf 30 -b:v 0 -c:a libopus -b:a 128k "%~ni.webm"

(Note: If using a .bat script, use %%i and %%~ni instead of %i and %~ni.)

Parameter Breakdown for Web Optimization

  • -i "$f": Specifies the input file.
  • -c:v libvpx-vp9: Encodes video using the VP9 codec, which delivers higher compression and lower file sizes suitable for modern web browsers.
  • -crf 30: Sets the Constant Rate Factor. Values range from 0 to 63; 30 is the recommended balance between quality and file size for web video. Lower numbers yield higher quality at the cost of larger files.
  • -b:v 0: Forces FFmpeg to use Constant Quality mode controlled by the CRF value rather than a constrained bitrate.
  • -c:a libopus: Encodes the audio track with the Opus codec, the standard high-efficiency audio format for WebM containers.
  • -b:a 128k: Sets the audio bitrate to 128 kbps, providing clear sound suitable for web playback.
