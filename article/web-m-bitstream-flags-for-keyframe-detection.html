WebM Bitstream Flags for Keyframe Detection

Detecting keyframes versus inter-frames in real-time WebM streams requires inspecting specific header flags at either the container level (Matroska/WebM) or within the raw video bitstream (VP8, VP9, or AV1). Real-time parsers typically inspect the SimpleBlock header flag for the fastest detection, but fallback bitstream parsing is necessary when dealing with raw codec payloads or unindexed streams.

Container-Level Detection (WebM SimpleBlock)

WebM is a subset of the Matroska (MKV) container format. In real-time streaming, video frames are packed into SimpleBlock elements.

Within each SimpleBlock, the container includes a 4-byte minimum header:

  • Track Number: EBML-encoded integer.
  • Timecode: 2 bytes (relative signed integer).
  • Flags Byte: 1 byte located immediately after the timecode.

To detect a keyframe at the container level:

  • Inspect Bit 7 (0x80 / Most Significant Bit) of the Flags byte.
  • 1 indicates a Keyframe (intra-frame, independent frame).
  • 0 indicates an Inter-frame (predictive frame).

VP8 Bitstream Keyframe Flag

If parsing raw VP8 payloads directly without container headers, inspect the 3-byte uncompressed frame header:

  • Byte 0, Bit 0 (Least Significant Bit): Represents the frame_type.
    • 0: Keyframe
    • 1: Inter-frame
  • Bytes 0–2: For keyframes (frame_type = 0), the next bytes contain a 3-byte start code (0x9D 0x01 0x2A) which validates the frame structure.

VP9 Bitstream Keyframe Flags

In VP9, frame types are determined by reading the uncompressed header bits sequentially:

  1. Frame Marker: The first 2 bits must be 10 (binary) to validate a VP9 frame.
  2. Profile: Read 1–3 bits (depending on whether profile bit 2 is set).
  3. Show Existing Frame Flag: 1 bit. If 1, it is not a new keyframe.
  4. Frame Type: 1 bit directly following the previous fields.
    • 0: KEY_FRAME
    • 1: NON_KEY_FRAME (Inter-frame)

AV1 Bitstream Flags

For WebM streams carrying AV1 video, frames are encapsulated in Open Bitstream Units (OBUs):

  1. OBU Header: Read the obu_type (Bits 3–6 of the first byte). Look for OBU_FRAME (type 6) or OBU_FRAME_HEADER (type 3).
  2. Uncompressed Header: Inside the frame header, parse the frame_type (2-bit enum):
    • 0: KEY_FRAME
    • 1: INTER_FRAME
    • 2: INTRA_ONLY_FRAME
    • 3: SWITCH_FRAME

Summary for Real-Time Pipelines

For optimal performance in low-latency WebM demuxing, check Bit 7 (0x80) of the SimpleBlock flags. If the stream arrives as raw RTP or depacketized video payloads, evaluate the least significant bit of byte 0 in VP8, the frame type bit following the profile in VP9, or the 2-bit frame_type field in AV1.
