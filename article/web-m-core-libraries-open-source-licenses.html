WebM Core Libraries Open Source Licenses

The core reference implementations of the WebM project are governed by permissive open-source licenses, primarily the revised BSD 3-Clause License paired with an explicit patent grant. This article outlines the specific licensing frameworks applied to the primary WebM codebases, including the container library libwebm, the video codec library libvpx, and the associated audio implementations.

The WebM Project Licensing Model

Google launched the WebM Project to provide a royalty-free, high-quality open video format for the web. To achieve widespread adoption, the project adopted a permissive licensing approach rather than copyleft terms (such as the GPL). The core tools and libraries are distributed under a standard 3-Clause BSD License, supplemented by a dedicated patent grant designed to protect users and contributors from patent litigation related to the format's implementation.

libvpx Licensing

The libvpx library serves as the reference implementation for both the VP8 and VP9 video codecs.

  • Software License: The source code of libvpx is licensed under the New BSD (3-Clause) License. This allows developers to redistribute, modify, and integrate the code into both open-source and proprietary software without requiring the resulting works to be open-source.
  • Additional Patent Grant: To resolve potential patent exposure, Google includes a specific "Additional IP Rights Grant (Patents)" file alongside the BSD license. This grant provides a perpetual, worldwide, non-exclusive, royalty-free patent license covering any patent claims owned by Google that are necessarily infringed by the software. The grant includes a defensive termination clause: if an entity initiates patent litigation against Google or other contributors alleging infringement by the implementation, the grant terminates for that entity.

libwebm Licensing

The libwebm library is the reference implementation for handling the WebM container format, which is based on a profile of Matroska (EBML).

  • Software License: Similar to libvpx, libwebm is distributed under the 3-Clause BSD License.
  • IP Grant: It utilizes the same accompanying patent grant terms as libvpx, ensuring developers can read, parse, and write WebM media containers without incurring royalty obligations.

Supporting Audio Implementations

WebM natively supports two audio formats: Opus and Vorbis. The reference implementations for these codecs use their own permissive licensing:

  • libopus: The reference library for the Opus audio codec is licensed under the 3-Clause BSD License, supported by patent promises from contributors including Xiph.Org, Skype/Microsoft, and Mozilla.
  • libvorbis: The reference implementation for the Vorbis audio codec is distributed by the Xiph.Org Foundation under the 3-Clause BSD License.
