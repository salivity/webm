Strip Vendor Tags from WebM Files for Privacy

WebM video containers frequently store embedded metadata, such as encoder signatures, hardware profiles, creation timestamps, and custom vendor-specific tags that can compromise personal privacy. Sanitizing these files requires specialized software utilities capable of reading and modifying the underlying Extensible Binary Meta Language (EBML) structure without re-encoding the media streams. This guide outlines the leading command-line and graphical tools available to completely strip identifying metadata and custom vendor tags from WebM files.

1. FFmpeg

FFmpeg is a versatile, open-source multimedia framework capable of stripping container metadata and vendor signatures while performing a stream copy, which avoids any loss of video or audio quality.

To remove all global metadata, custom tags, and default encoder strings, use the -map_metadata flag along with the bitexact flag:

ffmpeg -i input.webm -map_metadata -1 -fflags +bitexact -c copy output.webm
  • -map_metadata -1: Removes all standard and custom metadata entries, including vendor-specific key-value pairs.
  • -fflags +bitexact: Prevents FFmpeg from writing its own vendor and encoder tags (such as the Writing application or Writing library tags) into the container header.
  • -c copy: Copies the audio and video streams directly without re-encoding, completing the operation in seconds.

2. MKVToolNix (mkvpropedit)

Because WebM is a restricted subset of the Matroska (MKV) format, tools built for Matroska can directly manipulate WebM containers. The mkvpropedit utility from the MKVToolNix suite allows users to modify or delete metadata elements in place without needing to rewrite the entire file.

To wipe embedded tags and identifying container elements using mkvpropedit, run:

mkvpropedit input.webm --tags all: --delete title --edit info --set "writing-application=" --set "muxing-application="
  • --tags all:: Purges all tag elements (vendor tags, comments, artist info) across all tracks and the container itself.
  • --delete title: Removes the global title tag if present.
  • --edit info --set "...": Overwrites the default muxing and writing software identification strings with empty values.

3. MAT2 (Metadata Anonymisation Toolkit v2)

MAT2 is a dedicated privacy utility developed specifically to sanitize files before publishing or sharing. Unlike general-purpose media editors, MAT2 focuses strictly on eliminating identifying digital footprints.

  • Usage: Available via both a command-line interface (mat2) and a graphical interface (mat2-gui).
  • Command: 
    mat2 input.webm
  • Functionality: MAT2 processes the file, strips non-essential metadata—including custom vendor parameters and recording dates—and outputs a clean copy named input.cleaned.webm.

4. ExifTool

Phil Harvey's ExifTool is a widely used utility for reading, writing, and erasing metadata across dozens of media formats. While its write support for EBML/WebM structures is more basic than FFmpeg or MKVToolNix, it effectively clears common identifying tags.

To strip all writable tags:

exiftool -all= -overwrite_original input.webm
  • -all=: Directs the tool to clear all standard tags, user comments, and generic metadata properties.
  • -overwrite_original: Discards the backup file and updates the file directly.

Summary of Best Practices

For absolute anonymity, a combination of FFmpeg (using -fflags +bitexact) and MKVToolNix yields the cleanest result, ensuring that neither original vendor data nor the sanitizer's own software signature remains embedded inside the final WebM file.
