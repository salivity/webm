Opus Sample Rates for WebM Audio Decoding

When decoding Opus audio streams encapsulated within a WebM container, the Opus specification defines five native sample rates: 8 kHz, 12 kHz, 16 kHz, 24 kHz, and 48 kHz. Although an Opus stream can accept input and produce output at these distinct rates, the internal architecture processes all audio at a unified reference clock of 48 kHz. This article details the specific sample rates supported by Opus in WebM and explains how decoders handle playback across different bandwidth modes.

Supported Native Decoding Sample Rates

The Opus codec (RFC 6716) and the WebM Opus container specification natively support the following decoding sample rates, corresponding to specific audio bandwidth classifications:

  • 8 kHz (8,000 Hz): Narrowband audio, typically used for basic voice communications and low-bitrate telephony.
  • 12 kHz (12,000 Hz): Mediumband audio, providing improved speech clarity over standard narrowband.
  • 16 kHz (16,000 Hz): Wideband audio, standard for high-definition voice and teleconferencing applications.
  • 24 kHz (24,000 Hz): Super-wideband audio, offering extended high-frequency response suitable for music and premium speech.
  • 48 kHz (48,000 Hz): Fullband audio, covering the entire human audible frequency spectrum up to 20 kHz.

WebM Container Specifications for Opus

Within a WebM container, audio metadata is stored in the TrackEntry element:

  • SamplingFrequency: According to WebM guidelines, this field is typically set to 48000.0 for Opus tracks, regardless of the original source audio sample rate.
  • OutputSamplingFrequency: Optional field used if the player is explicitly instructed to downsample or adjust the output frequency during playback.

Because Opus internally handles band transitions seamlessly within a single stream, WebM treats 48 kHz as the canonical clock rate for timestamp calculations, frame durations, and default stream playback.

Decoder Resampling Behavior

Compliant Opus decoders include built-in resampling filters that natively map between the internal processing rates:

  1. Standard 48 kHz Output: By default, standard Opus decoders output uncompressed PCM audio at 48 kHz, automatically upsampling lower-rate frames internally without requiring external audio resamplers.
  2. Targeted Output Rates: If an application requests output at 8, 12, 16, or 24 kHz to save processing power or match system hardware, the decoder's built-in resampler can output directly at any of these supported rates natively.
  3. Non-Native Rates (e.g., 44.1 kHz, 96 kHz): Rates such as 44.1 kHz or 88.2 kHz are not part of the native Opus core specification. When decoding to 44.1 kHz, the stream is decoded at one of the native rates (usually 48 kHz) and then passed through an external sample rate conversion (SRC) layer.
