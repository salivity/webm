Tools to Edit WebM TrackUID and TrackNumber

Modifying the TrackUID and TrackNumber elements in a WebM file requires utilities capable of reading and manipulating the Extensible Binary Meta Language (EBML) structure underpinning the Matroska and WebM container formats. This article outlines the most effective software tools available to edit these specific track identifiers, ranging from specialized command-line utilities to EBML tree editors and programming libraries.

1. MKVToolNix (mkvpropedit)

Because WebM is a subset of the Matroska (MKV) specification, tools from the MKVToolNix suite are fully capable of processing WebM files. The command-line utility mkvpropedit is the standard tool for this task because it edits file headers in-place without requiring a complete file remux.

  • Targeting Elements: You can select a track by its position or type (e.g., track:v1 for the first video track or track:a1 for the first audio track).
  • Usage Example: 
    mkvpropedit "video.webm" --edit track:1 --set track-number=2 --set track-uid=123456789
  • Pros: Fast, preserves all media streams intact, and prevents accidental container corruption.

2. 010 Editor with the EBML Template

For low-level inspection and editing, 010 Editor combined with its community EBML/Matroska template provides a graphical hex-level interface mapped to WebM syntax.

  • Targeting Elements: In the template results pane, navigate to the Segment -> Tracks -> TrackEntry section. Inside, locate the TrackNumber (EBML ID 0xD7) and TrackUID (EBML ID 0x73C5) tags.
  • Usage: Click directly on the values in the template variable tree to modify the integers, then save the file.
  • Pros: Offers exact byte-level control without automatic recalculation of non-targeted data.

3. ebmlite (Python Library)

If you require automated or programmatic manipulation, ebmlite is a lightweight Python package designed to parse and re-serialize EBML documents like MKV and WebM based on schema definitions.

  • Targeting Elements: Open the WebM file using the Matroska schema, iterate through Segment.Tracks, find the target TrackEntry, and update the value attributes for TrackNumber and TrackUID.
  • Pros: Ideal for batch processing workflows where manual CLI commands or GUI editors are impractical.

Note on FFmpeg

While FFmpeg can manipulate track order, mapping, and stream metadata flags (such as disposition and metadata tags), it automatically generates its own internal TrackUID values upon muxing. As a result, FFmpeg cannot be used to force arbitrary, custom values into TrackUID or TrackNumber during standard transcoding or remuxing procedures. For precise element overrides, dedicated Matroska/EBML tools like mkvpropedit remain the appropriate choice.
