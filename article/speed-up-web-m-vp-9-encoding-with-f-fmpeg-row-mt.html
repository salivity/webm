Speed Up WebM VP9 Encoding with FFmpeg Row-MT

Encoding WebM videos using the VP9 codec (libvpx-vp9) in FFmpeg can be exceptionally resource-intensive and slow by default. By enabling row-based multithreading alongside proper tile configurations, you can fully utilize modern multi-core processors to significantly accelerate your encoding speeds without compromising video quality. This guide demonstrates how to configure the necessary flags in FFmpeg to activate row-based multithreading for WebM VP9 encoding.

The Key Parameter: -row-mt 1

The primary flag used to enable row-based multithreading in FFmpeg's libvpx-vp9 encoder is -row-mt 1.

Standard multi-threading in VP9 splits frames into vertical column tiles, which often leaves several CPU threads idle if the resolution does not allow for enough columns. Enabling -row-mt 1 allows the encoder to process rows across different tiles simultaneously, distributing the workload across available CPU cores much more efficiently.

Required Supporting Parameters

To maximize the benefits of -row-mt 1, combine it with the following flags:

  • -threads <number>: Specifies the number of CPU threads FFmpeg should allocate to the encoder (e.g., -threads 8 or -threads 16).
  • -tile-columns <number>: Sets the number of column tiles (\(2^N\)). For example, -tile-columns 2 creates 4 column tiles, which is optimal for 1080p content.
  • -tile-rows <number>: Sets the number of row tiles (\(2^N\)), typically set to 1 or 2 for high-resolution footage.

Example FFmpeg Command

Below is an example of a constant quality (CRF) WebM encoding command utilizing row-based multithreading:

ffmpeg -i input.mp4 -c:v libvpx-vp9 -crf 30 -b:v 0 -row-mt 1 -tile-columns 2 -tile-rows 1 -threads 8 -c:a libopus -b:a 128k output.webm

Breakdown of the Command:

  • -c:v libvpx-vp9: Uses the VP9 video encoder inside the WebM container.
  • -crf 30 -b:v 0: Enables Constant Quality mode (CRF values typically range from 15 to 35 for VP9).
  • -row-mt 1: Activates row-based multithreading.
  • -tile-columns 2: Divides the video frame into \(2^2 = 4\) columns.
  • -threads 8: Allocates 8 CPU threads to the encoding process.
  • -c:a libopus -b:a 128k: Encodes the audio using the standard Opus codec at 128 kbps.

Recommended Tile Settings by Resolution

Adjust -tile-columns based on your source resolution to get the best performance with -row-mt 1:

  • 720p and below: -tile-columns 1 (2 tiles)
  • 1080p: -tile-columns 2 (4 tiles)
  • 4K (2160p): -tile-columns 3 (8 tiles)
