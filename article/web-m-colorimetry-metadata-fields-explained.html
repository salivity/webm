WebM Colorimetry Metadata Fields Explained

The WebM container format, based on Matroska (EBML), includes comprehensive colorimetry metadata support within its video track definitions to handle both Standard Dynamic Range (SDR) and High Dynamic Range (HDR) video. This metadata ensures that decoders, web browsers, and display hardware correctly interpret color gamuts, transfer curves, quantization ranges, and mastering display parameters.

Modern WebM specifications define color metadata within the Colour element (EBML ID 0x55B0), nested inside the Video track settings. The supported fields include:

Color Space and Representation Fields

  • MatrixCoefficients (0x55B1): Identifies the matrix coefficients used to derive luma and chroma signals from red, green, and blue color primaries. Supported values map to ITU-R and ISO/IEC standards, including BT.709, BT.601 (SMPTE 170M / BT.470 System B, G), SMPTE 240M, and BT.2020 (non-constant and constant luminance).
  • BitsPerChannel (0x55B2): Specifies the bit depth per color channel (e.g., 8, 10, or 12 bits).
  • ChromaSubsamplingHorz (0x55B3) & ChromaSubsamplingVert (0x55B4): Indicates the horizontal and vertical chroma subsampling factors (e.g., 4:2:0, 4:2:2, 4:4:4).
  • ChromaSitingHorz (0x55B7) & ChromaSitingVert (0x55B8): Defines the exact spatial positioning of chroma samples relative to luma samples (e.g., unspecified, left-collocated, half/centered).
  • Range (0x55B9): Specifies the clipping/quantization range of the video signal:
    • 0: Unspecified
    • 1: Broadcast/Limited range (e.g., 16–235 for 8-bit luma)
    • 2: Full range (0–255 for 8-bit)
    • 3: Defined by MatrixCoefficients/TransferCharacteristics

Colorimetry and Transfer Curves

  • TransferCharacteristics (0x55BA): Defines the Electro-Optical Transfer Function (EOTF) or opto-electronic transfer function of the source. Supported values include BT.709, BT.470M, BT.470BG, SMPTE 170M, Linear, sRGB, SMPTE ST 2084 (PQ / Perceptual Quantizer for HDR10), and ARIB STD-B67 (HLG / Hybrid Log-Gamma).
  • Primaries (0x55BB): Identifies the chromaticity coordinates of the source color primaries. Supported profiles include BT.709, BT.470M, BT.470BG, SMPTE 170M, SMPTE 240M, Film, BT.2020, SMPTE ST 428-1 (CIE 1931 XYZ), and SMPTE RP 431-2 / RP 432-1 (DCI-P3 / P3-D65).

HDR Static Metadata Fields

  • MaxCLL (0x55BC): Maximum Content Light Level, defined as the maximum pixel brightness of the content in candelas per square meter (\(cd/m^2\) or nits).
  • MaxFALL (0x55BD): Maximum Frame-Average Light Level, representing the highest average brightness for any single frame in nits.

Mastering Display Metadata (MasteringMetadata - 0x55D0)

For HDR content following SMPTE ST 2086, the MasteringMetadata sub-element contains coordinates defining the color volume and luminance limits of the reference mastering monitor:

  • PrimaryRChromaticityX / PrimaryRChromaticityY (0x55D1, 0x55D2): Red primary CIE 1931 coordinates.
  • PrimaryGChromaticityX / PrimaryGChromaticityY (0x55D3, 0x55D4): Green primary CIE 1931 coordinates.
  • PrimaryBChromaticityX / PrimaryBChromaticityY (0x55D5, 0x55D6): Blue primary CIE 1931 coordinates.
  • WhitePointChromaticityX / WhitePointChromaticityY (0x55D7, 0x55D8): Reference white point CIE 1931 coordinates (commonly D65).
  • LuminanceMax (0x55D9): Maximum display luminance of the mastering monitor in \(cd/m^2\).
  • LuminanceMin (0x55DA): Minimum display luminance of the mastering monitor in \(cd/m^2\).
