HLG HDR Transfer Characteristics in WebM Video

This article explains how the WebM container format defines and stores the transfer characteristics necessary for Hybrid Log-Gamma (HLG) High Dynamic Range (HDR) video. WebM relies on Matroska-derived EBML metadata structures and standardized codec-level signaling within VP9 or AV1 bitstreams to accurately signal HLG (ITU-R BT.2100 / ARIB STD-B67) electro-optical transfer functions to decoders and display pipelines.

Container-Level Signaling via EBML

WebM is a subset of the Matroska (MKV) container format and utilizes Extensible Binary Meta Language (EBML) to organize media streams. Color metadata is represented within the video track configuration under the Colour master element (EBML ID 0x55B0).

To represent HLG HDR, WebM utilizes the TransferCharacteristics element (EBML ID 0x55BA) situated inside the Colour element. The value assigned to this element corresponds to standard ITU-T H.273 / ISO/IEC 23091-2 Video Parameter Values:

  • Value 18 (ARIB STD-B67 / BT.2100-2 HLG): Explicitly identifies the transfer characteristics as Hybrid Log-Gamma. This instructs the rendering engine and display pipeline to apply the HLG inverse opto-electronic transfer function (OETF) and appropriate system gamma based on nominal peak display brightness.

Complementary Color Space Elements

For proper HLG HDR reproduction, the TransferCharacteristics element operates alongside other metadata tags within the Colour container to define the complete color volume:

  • MatrixCoefficients (EBML ID 0x55B1): Typically set to 9 (ITU-R BT.2020 non-constant luminance) for HDR workflows.
  • ColourPrimaries (EBML ID 0x55B9): Typically set to 9 (ITU-R BT.2020), ensuring accurate wide color gamut (WCG) mapping.
  • BitsPerChannel (EBML ID 0x55B2): Set to 10 or 12 to provide the bit depth required to prevent banding in HDR playback.

Codec Bitstream Integration

In addition to container-level EBML tags, WebM video tracks (predominantly VP9 and AV1) duplicate these color parameters directly in the encoded bitstream to ensure compatibility across various decoding APIs:

  • VP9 Bitstream: Color attributes are signaled in the sequence header within the color_config() syntax. When encoding HLG, the color_transfer_characteristics parameter is explicitly set to 18.
  • AV1 Bitstream: Color information is defined in the Sequence Header OBU (Open Bitstream Unit) via the color_config struct. The transfer_characteristics field is set to 18 (BT_2100_HLG).

By providing this data at both the container layer (WebM EBML) and the elementary stream layer (VP9/AV1), media players, browsers, and hardware decoders can detect HLG parameters prior to decoding, properly configuring the system compositor and display hardware for HDR output.
