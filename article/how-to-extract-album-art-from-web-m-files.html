How to Extract Album Art from WebM Files

WebM files, commonly used for web video and audio, often contain embedded thumbnails or album artwork stored as attached metadata or separate image streams. Extracting these images allows you to recover high-resolution cover art without re-encoding the entire media file. This guide covers the most effective methods to extract embedded images from WebM files using command-line tools like FFmpeg and MKVToolNix, as well as graphical applications.

Method 1: Extracting Images Using FFmpeg

FFmpeg is the most versatile tool for extracting embedded media streams. In WebM files, cover art is typically stored as a dedicated video stream (often an image codec like MJPEG or PNG) or as an attachment.

Step 1: Inspect the WebM File

Run the following command to check the internal streams of your WebM file:

ffmpeg -i input.webm

Look for a stream labeled with attached_pic or a secondary video stream containing mjpeg, png, or webp.

Step 2: Extract the Image Stream

If the thumbnail is stored as an attached image or secondary video stream, extract it directly without re-encoding:

ffmpeg -i input.webm -map 0:v -c copy -frames:v 1 cover.jpg

If the file has multiple video streams (e.g., Stream #0:0 is video, Stream #0:1 is the cover art), target the specific stream index:

ffmpeg -i input.webm -map 0:v:1 -c copy cover.jpg

Step 3: Extracting Matroska Attachments

Because WebM is based on the Matroska container, embedded artwork can also be stored as an attachment. Extract all attachments using:

ffmpeg -dump_attachment:t "" -i input.webm

Method 2: Extracting Images Using MKVToolNix

MKVToolNix is built specifically for Matroska and WebM containers, making it ideal for extracting embedded assets.

Using mkvextract (Command Line)

  1. List the track and attachment IDs: 
    mkvmerge -i input.webm
  2. Extract the attachment using its ID: 
    mkvextract attachments input.webm 1:cover.jpg
    (Replace 1 with the attachment ID shown in the previous output.)

Using MKVToolNix GUI

  1. Open MKVToolNix GUI.
  2. Drag and drop your .webm file into the Source files section.
  3. Look at the Tracks, chapters and tags or Attachments section at the bottom.
  4. Right-click the image file under Attachments and select Save attachment.

Method 3: Using GUI Metadata Editors (Mp3tag or Kid3)

If you prefer an interface and are working with audio-centric WebM files:

  1. Download and open Mp3tag or Kid3.
  2. Load the WebM audio file.
  3. Locate the album art preview box in the metadata panel.
  4. Right-click the displayed artwork and choose Extract cover... or Save to file....
