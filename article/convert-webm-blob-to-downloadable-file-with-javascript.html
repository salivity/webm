Convert WebM Blob to Downloadable File with JavaScript

Converting a recorded WebM Blob into a downloadable file link is a common requirement when working with the MediaStream Recording API in JavaScript. This process involves generating a temporary DOM object URL from the binary Blob data, creating an HTML anchor element programmatically, setting the download attributes, and triggering a synthetic click event to initiate the browser download.

Step-by-Step Implementation

To turn a WebM Blob into a downloadable file link, follow these standard steps:

  1. Create an Object URL: Use URL.createObjectURL() to map the WebM Blob to a temporary URL string accessible by the browser.
  2. Create an Anchor Tag: Create an <a> element in memory using document.createElement('a').
  3. Set Attributes: Assign the generated Object URL to the href attribute and assign your desired file name (e.g., recording.webm) to the download attribute.
  4. Trigger the Download: Programmatically call the .click() method on the anchor element.
  5. Clean Up Memory: Call URL.revokeObjectURL() to release memory allocated to the temporary URL.

JavaScript Code Example

Below is a complete, reusable function to trigger a direct download from a WebM Blob:

function downloadWebMBlob(blob, fileName = 'recording.webm') {
  // Ensure the blob is explicitly typed as WebM
  const webmBlob = blob.type === 'video/webm' 
    ? blob 
    : new Blob([blob], { type: 'video/webm' });

  // Step 1: Create a temporary Object URL
  const url = URL.createObjectURL(webmBlob);

  // Step 2: Create a hidden anchor element
  const anchor = document.createElement('a');
  anchor.style.display = 'none';
  anchor.href = url;
  anchor.download = fileName;

  // Step 3: Append, trigger click, and remove
  document.body.appendChild(anchor);
  anchor.click();
  document.body.removeChild(anchor);

  // Step 4: Revoke the Object URL to free up memory
  setTimeout(() => {
    URL.revokeObjectURL(url);
  }, 100);
}

Displaying a Visible Download Link

If you prefer to render a clickable link on the UI instead of triggering an automatic download, you can attach the URL directly to an existing anchor element on the page:

function createVisibleDownloadLink(blob, containerId, fileName = 'recording.webm') {
  const url = URL.createObjectURL(blob);
  const link = document.createElement('a');

  link.href = url;
  link.download = fileName;
  link.textContent = `Download ${fileName}`;
  link.className = 'download-btn';

  // Revoke the object URL after the user clicks the link
  link.addEventListener('click', () => {
    setTimeout(() => URL.revokeObjectURL(url), 1000);
  });

  document.getElementById(containerId).appendChild(link);
}

Key Considerations

  • Memory Management: Always revoke the generated object URL with URL.revokeObjectURL() once the download starts. Failing to do so can cause memory leaks, especially when recording large video files.
  • MIME Types: Ensure the Blob includes { type: 'video/webm' } or { type: 'audio/webm' } so media players recognize the container format correctly upon download.
