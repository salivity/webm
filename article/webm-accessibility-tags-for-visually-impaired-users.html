WebM Accessibility Tags for Visually Impaired Users

In the WebM container specification, accessibility tracks for visually impaired users—commonly known as audio descriptions—are designated at the container level using the FlagVisualImpaired element nested within a TrackEntry. When WebM video is distributed across modern web platforms, this internal metadata works alongside the HTML5 <track kind="descriptions"> element to signal, select, and play narrated descriptions of visual content. This guide outlines the specific container tags, elements, and implementation details required to identify and deliver accessible audio descriptions in WebM files.

The WebM FlagVisualImpaired Container Element

WebM is a restricted subset of the Matroska (EBML) multimedia container format. In Matroska and WebM container architecture, every audio, video, or subtitle stream is defined within a TrackEntry master element located inside the global Tracks container.

To designate an audio stream as an accessibility track for individuals with visual impairments, the container utilizes:

  • Element Name: FlagVisualImpaired
  • EBML ID: 0x55AA
  • Element Type: Unsigned Integer (Boolean)
  • Value: Set to 1 (True) to mark the track as intended for visually impaired users; set to 0 (False) for standard tracks.

When a media player parses the WebM header, detecting FlagVisualImpaired set to 1 informs the playback engine that the stream contains narrated descriptions of on-screen visual elements (actions, facial expressions, scene changes) timed to fit between natural dialogue pauses.

Complementary TrackEntry Elements

The FlagVisualImpaired flag does not work in isolation. To function correctly, it must be paired with standard identifying metadata inside the same TrackEntry:

  • TrackType (0x83): Must be set to 2 (Audio).
  • **Language (0x22B59C) or LanguageBCP47 (0x22B59D): Identifies the language of the description stream (e.g., eng or en-US), allowing players to automatically match the user's preferred accessibility language.
  • Name (0x536E): A UTF-8 string, such as "Audio Description" or "English Descriptive Audio," displayed in the user interface during track selection.
  • FlagDefault (0x88): Typically set to 0 (False) on audio description tracks so that standard users do not hear the descriptions by default, unless the file is an accessibility-first distribution.

HTML5 Integration: The <track> Container Tag

When delivering WebM media over the web, browsers rely on the HTML5 media framework to expose accessibility options directly to screen readers and user agent controls. The corresponding web container tag is:

<video controls>
  <source src="video.webm" type="video/webm">
  <track kind="descriptions" src="descriptions.vtt" srclang="en" label="Audio Description">
</video>

The attribute kind="descriptions" specifically designates text or synthesized speech descriptions of the video track for visually impaired users. When using pre-mixed secondary audio tracks embedded directly within the WebM container, modern media frameworks read the underlying FlagVisualImpaired tag to surface the stream in the browser's native audio track selection menu.
