Edit WebM Color Space Metadata Without Re-Encoding

WebM video files store essential color space metadata—including color primaries, matrix coefficients, transfer characteristics, and range—within EBML container headers or internal codec bitstreams. Incorrectly tagged files can result in washed-out colors or improper HDR-to-SDR mapping across different media players and browsers. Fortunately, because WebM is a restricted subset of the Matroska (MKV) container, you can inspect and modify these color parameters in seconds using container-level header editors and remuxing utilities without the quality loss or processing overhead of full video re-encoding.

Tools for Previewing WebM Color Metadata

Before modifying a file, you need tools that read and display stream- and container-level metadata without altering the underlying video track.

1. MediaInfo

MediaInfo is the standard cross-platform utility for checking video parameters. It displays detailed color information in its GUI or command-line interface, including:

  • Color range: Limited (TV) or Full (PC)
  • Color primaries: BT.709, BT.2020, etc.
  • Transfer characteristics: BT.709, SMPTE 2084 (PQ), HLG
  • Matrix coefficients: BT.709, BT.2020 non-constant luminance

2. FFprobe

Part of the FFmpeg suite, ffprobe extracts container- and stream-level color metadata directly from the command line.

Command to preview stream color properties:

ffprobe -v error -select_streams v:0 -show_entries stream=color_range,color_space,color_primaries,color_transfer -of default=noprint_wrappers=1 input.webm

3. MKVToolNix (mkvinfo)

mkvinfo outputs the raw EBML element tree of Matroska and WebM files. It allows you to verify whether the container includes the Colour sub-elements (MatrixCoefficients, BitsPerChannel, Primaries, TransferCharacteristics, and Range) under the video track definition.

Tools for Adjusting WebM Color Metadata Without Re-Encoding

1. MKVToolNix (mkvpropedit & Header Editor)

MKVToolNix is the most efficient solution for lossless metadata modification. Its command-line component, mkvpropedit, modifies file headers directly in place within milliseconds.

Common mkvpropedit Parameters for WebM:

  • --set colour-matrix-coefficients=<value> (e.g., 1 for BT.709, 9 for BT.2020)
  • --set colour-primaries=<value> (e.g., 1 for BT.709, 9 for BT.2020)
  • --set colour-transfer-characteristics=<value> (e.g., 1 for BT.709, 16 for PQ/HDR10)
  • --set colour-range=<value> (1 for broadcast/limited range, 2 for full range)

Example Command:

To tag a WebM file with standard Rec.709 parameters in-place:

mkvpropedit input.webm --edit track:v1 --set colour-matrix-coefficients=1 --set colour-primaries=1 --set colour-transfer-characteristics=1 --set colour-range=1

Note: MKVToolNix GUI also features a visual Header Editor where you can open a WebM file, navigate to the video track's color properties, change the dropdown values, and save instantly.

2. FFmpeg (Stream Copy / Remuxing)

FFmpeg can rewrite container headers and inject bitstream filters without decoding the video frames using -c copy.

Remuxing with WebM-Specific Container Metadata:

ffmpeg -i input.webm -c copy -color_primaries bt709 -color_trc bt709 -colorspace bt709 -color_range tv output.webm

Modifying VP9 Codec-Level Bitstream Metadata:

For WebM files using the VP9 codec, the color space may also be defined inside the VP9 bitstream itself. FFmpeg provides the vp9_metadata bitstream filter to alter these values losslessly:

ffmpeg -i input.webm -c:v copy -bsf:v vp9_metadata=color_space=bt709:color_range=tv -c:a copy output.webm

Supported color_space values for the filter include bt709, bt601, bt2020-ncl, and smpte240m.
