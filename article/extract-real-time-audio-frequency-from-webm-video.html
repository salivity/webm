Extract Real-Time Audio Frequency from WebM Video

Extracting real-time audio frequency data from a playing WebM video allows developers to build dynamic visualizations, audio reactive interfaces, and analysis tools in the browser. By routing the audio from an HTML5 video element through the Web Audio API's AudioContext and AnalyserNode, you can continuously read frequency spectrum data using modern JavaScript.

1. Set Up the Video Element

Create a standard HTML5 <video> tag pointing to your WebM video file. If the video is hosted on a different domain, include the crossorigin="anonymous" attribute to prevent CORS restrictions from blocking audio processing.

<video id="webmVideo" src="sample.webm" controls crossorigin="anonymous"></video>

2. Initialize the Audio Context and Analyser

Create an instance of AudioContext and instantiate an AnalyserNode. The AnalyserNode provides access to frequency and time-domain analysis.

const video = document.getElementById('webmVideo');
const audioCtx = new (window.AudioContext || window.webkitAudioContext)();
const analyser = audioCtx.createAnalyser();

// Set FFT (Fast Fourier Transform) size; must be a power of 2
analyser.fftSize = 256;

3. Connect the Audio Pipeline

Feed the video's audio output into the Web Audio API pipeline using createMediaElementSource(). Route the source node through the analyser node, and finally connect the analyser to audioCtx.destination so the audio remains audible through the user's speakers.

const source = audioCtx.createMediaElementSource(video);
source.connect(analyser);
analyser.connect(audioCtx.destination);

Note: Most browsers require a user interaction (such as clicking play) before an AudioContext can transition out of a suspended state.

video.addEventListener('play', () => {
  if (audioCtx.state === 'suspended') {
    audioCtx.resume();
  }
  renderFrame();
});

4. Read Frequency Data in Real Time

Create a typed array to store the frequency bins. The size of this array corresponds to analyser.frequencyBinCount, which is half of the fftSize. Use requestAnimationFrame to sample the frequency data on every frame refresh.

const bufferLength = analyser.frequencyBinCount;
const dataArray = new Uint8Array(bufferLength);

function renderFrame() {
  if (!video.paused && !video.ended) {
    requestAnimationFrame(renderFrame);
  }

  // Populate dataArray with current frequency values (0 to 255)
  analyser.getByteFrequencyData(dataArray);

  // Example: Log or visualize dataArray
  console.log(dataArray);
}

Complete Implementation

const video = document.getElementById('webmVideo');
let audioCtx;
let analyser;
let dataArray;

function setupAudioPipeline() {
  audioCtx = new (window.AudioContext || window.webkitAudioContext)();
  analyser = audioCtx.createAnalyser();
  analyser.fftSize = 128;

  const source = audioCtx.createMediaElementSource(video);
  source.connect(analyser);
  analyser.connect(audioCtx.destination);

  dataArray = new Uint8Array(analyser.frequencyBinCount);
}

function updateFrequencyData() {
  if (!video.paused && !video.ended) {
    analyser.getByteFrequencyData(dataArray);
    
    // Process frequency bins (e.g., update canvas visualizer here)
    
    requestAnimationFrame(updateFrequencyData);
  }
}

video.addEventListener('play', () => {
  if (!audioCtx) {
    setupAudioPipeline();
  }
  if (audioCtx.state === 'suspended') {
    audioCtx.resume();
  }
  updateFrequencyData();
});

Key Considerations

  • fftSize Configuration: Higher values (e.g., 1024, 2048) yield higher frequency resolution at the expense of time precision. Lower values (e.g., 64, 128, 256) prioritize responsiveness.
  • CORS Restrictions: If the WebM source is external, the remote server must return proper Access-Control-Allow-Origin headers, or the Web Audio API will output silence.
  • Single Source Limitation: An HTMLMediaElement can only be connected to createMediaElementSource once per page lifecycle. Initialize the source only once to prevent runtime errors.
