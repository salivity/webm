Evaluating WebM Compression With SSIM and VMAF

Automated video quality metrics like the Structural Similarity Index Measure (SSIM) and Video Multi-Method Assessment Fusion (VMAF) evaluate WebM video compression by comparing compressed video frames against the uncompressed reference source. This article explains the underlying mechanics of SSIM and VMAF, how they quantify visual degradation caused by WebM codecs like VP8, VP9, and AV1, and why these automated measurements are critical for modern video encoding pipelines.

The Challenge of Evaluating WebM Compression

WebM is an open, royalty-free media file format primarily using VP8, VP9, or AV1 video codecs. These codecs use lossy compression techniques—such as spatial intra-prediction, temporal inter-frame motion compensation, transform coding, and quantization—to reduce file size.

While lossy compression saves bandwidth, it introduces visual artifacts including:

  • Blocking: Grid patterns resulting from block-based discrete cosine or directional transforms.
  • Blurring: Loss of high-frequency detail due to heavy quantization.
  • Ringing: Halos around sharp edges.
  • Temporal flickering: Inconsistencies between consecutive frames in low-bitrate scenes.

Traditional mathematical metrics like Peak Signal-to-Noise Ratio (PSNR) only measure absolute pixel error (Mean Squared Error), often failing to reflect how humans actually perceive these artifacts. SSIM and VMAF address this limitation by modeling human visual perception.

How SSIM Evaluates WebM Compression

SSIM evaluates quality based on the premise that the human visual system (HVS) is highly adapted to extract structural information from a visual scene, rather than measuring absolute pixel brightness.

Mechanics of SSIM

SSIM compares corresponding local pixel windows (\(N \times N\)) between the original reference frame and the compressed WebM frame across three distinct components:

  1. Luminance (\(l\)): Measures the closeness of the mean pixel intensities.
  2. Contrast (\(c\)): Measures the closeness of the standard deviations (variances) of pixel intensities.
  3. Structure (\(s\)): Measures the correlation coefficient between the two windows after removing luminance and contrast variations.

The combined formula yields a score between -1 and 1 (typically 0 to 1 for video), where 1 indicates an exact duplicate of the source.

Application to WebM

When applied to WebM files, SSIM effectively flags spatial distortions. For example, if VP9's adaptive quantization aggressively compresses flat backgrounds, SSIM detects the loss of texture and contrast in those local blocks. Advanced variations, such as Multi-Scale SSIM (MS-SSIM), evaluate images across multiple resolutions to better simulate viewing distances.

How VMAF Evaluates WebM Compression

Developed by Netflix, VMAF is an advanced, perceptual full-reference metric designed specifically for video streaming. Unlike SSIM, which only assesses static spatial properties, VMAF combines multiple quality features with machine learning to predict subjective Mean Opinion Scores (MOS).

Core Components of VMAF

VMAF computes multiple elementary metrics per frame and fuses them using a Support Vector Machine (SVM) regressor:

  • Visual Information Fidelity (VIF): Measures information loss at multiple spatial scales, capturing how quantization in WebM codecs alters edge details and texture.
  • Detail Loss Metric (DLM): Measures the loss of details that distract the viewer, as well as the introduction of impairments that draw visual attention.
  • Motion: Measures temporal differences between adjacent luminance frames to account for motion perception and temporal artifacts.

VMAF outputs a score from 0 to 100, where higher scores represent higher perceived quality (a score around 93–95 is generally considered visually lossless to the typical viewer).

Application to WebM

VMAF is particularly effective for evaluating VP9 and AV1 encodes within WebM because it accurately penalizes:

  • Motion-prediction errors and ghosting artifacts during high-motion scenes.
  • Text smoothing and grain loss, common in high-efficiency AV1 encoding.
  • Temporal instability caused by aggressive keyframe intervals.

The Automated Evaluation Workflow

To evaluate a WebM file using SSIM or VMAF:

  1. Decoding: Both the original uncompressed source and the compressed WebM file are decoded to raw YUV pixel formats.
  2. Frame Alignment: Frames are synchronized temporally and spatially. If the WebM video was downscaled during encoding, it must be upscaled back to the source resolution using a standard filter (such as bicubic) before metric calculation.
  3. Computation: Metrics are calculated on the luminance (\(Y\)) channel frame-by-frame.
  4. Aggregation: Frame scores are aggregated into statistical summaries (mean, harmonic mean, 1st percentile) to identify both overall video quality and momentary quality drops.
