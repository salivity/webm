Fix Transparent WebM Alpha Halo Artifacts

Halo artifacts around transparent WebM videos—appearing as faint black, gray, or white outlines along semi-transparent edges—are caused by mismatched alpha channel premultiplication settings. These visual glitches happen when video content rendered with a premultiplied background is interpreted as straight alpha during web playback. To prevent these halos entirely, transparent WebM files must always be exported and encoded using Straight (Unmatted) Alpha.

The Cause: Straight Alpha vs. Premultiplied Alpha

To understand why halos appear, it is essential to understand how transparency is calculated:

  • Straight Alpha (Unassociated): The color channels (RGB) and the transparency channel (Alpha) are stored completely independently. Color values at the edge of an object remain at 100% saturation, and the alpha channel strictly defines the opacity level.
  • Premultiplied Alpha (Associated): The RGB color values are multiplied by the alpha values against a specific background color (usually solid black or solid white) during export.

Web browsers and standard HTML5 <video> players expect transparent WebM files (encoded via VP8 or VP9) to use Straight Alpha. When a premultiplied video is played in an environment expecting straight alpha, the player renders the pre-baked background color around anti-aliased and semi-transparent edges, creating a dark or light halo artifact.

The Solution: Correct Premultiplication Settings

To eliminate halos, set your rendering pipeline to export straight alpha rather than premultiplied alpha.

Adobe After Effects

  1. Add your composition to the Render Queue.
  2. Open the Output Module Settings.
  3. Set the Channels dropdown to RGB + Alpha.
  4. Under the Color setting, change the selection from Premultiplied (Matted) to Straight (Unmatted).
  5. Export to an intermediate format with alpha support (such as ProRes 4444 or PNG sequence) before converting to WebM.

Blender

  1. Navigate to the Render Properties tab.
  2. Under the Film dropdown, check the Transparent box.
  3. In the Output Properties tab, choose a format that supports alpha (such as PNG or OpenEXR) and ensure the color mode is set to RGBA.
  4. Blender natively processes transparent renders with straight alpha in standard image outputs, avoiding matte color blending.

FFmpeg Encoding Settings

When converting an intermediate transparent file (like Apple ProRes 4444) to WebM VP9 using FFmpeg, ensure you preserve the alpha channel correctly without forcing background matting:

ffmpeg -c:v prores_ks -i input.mov -c:v libvpx-vp9 -pix_fmt yuva420p -b:v 2M -auto-alt-ref 0 output.webm
  • -pix_fmt yuva420p: Ensures the inclusion of the A (Alpha) channel in the pixel format.
  • -auto-alt-ref 0: Disables alternative reference frames, which is required in older VP9 encoders to prevent alpha channel corruption and edge bleeding.

Additional Edge-Fringing Troubleshooting

  • Matte Removal in Compositing: If you are working with source footage that already has a black outline baked in, apply an "Unmult" effect or an Alpha Cleaner plugin before final export to strip away the underlying black matte.
  • Avoid Screen/Additive Blending for Web Alpha: Blending modes that depend on black backgrounds to simulate transparency (such as Screen or Add) will not translate to an alpha channel and will export with hard black edges unless manually converted to an alpha matte.
