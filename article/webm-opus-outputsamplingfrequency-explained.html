WebM Opus OutputSamplingFrequency Explained

The OutputSamplingFrequency element in a WebM container defines the intended playback or original audio sampling rate for an Opus audio track. Because the Opus codec internally decodes audio at a fixed 48 kHz rate, this Matroska/WebM metadata element allows media players and audio renderers to identify the original source frequency (such as 44.1 kHz) and correctly configure output devices or resamplers without losing track of the initial audio properties.

In the WebM and Matroska specifications, audio tracks use two distinct frequency-related elements: SamplingFrequency and OutputSamplingFrequency. For Opus streams, standard container mappings require the standard SamplingFrequency element to be set to 48000 Hz. This reflects the native processing and output rate of the Opus decoding engine.

The OutputSamplingFrequency element serves several practical functions:

  • Defining the Original Sample Rate: If the original source material was recorded at a different rate (e.g., 44.1 kHz, 22.05 kHz, or 16 kHz), this element stores that value. It indicates to playback software what the native frequency was before the encoder resampled or mapped it to Opus's internal processing pipeline.
  • Guiding Resampling and Playback Pipelines: Audio rendering frameworks use this value to determine whether they should downsample or upsample the decoded 48 kHz audio stream to match the user's hardware configuration or to restore the track's original playback characteristics.
  • Audio/Video Synchronization: Certain media engines use the output frequency parameter to calibrate timestamp calculations, clock synchronization, and sample counting, ensuring long-term sync across diverse playback environments.

If OutputSamplingFrequency is not explicitly set in the WebM header, playback clients default to using the value of SamplingFrequency (48000 Hz for Opus).
