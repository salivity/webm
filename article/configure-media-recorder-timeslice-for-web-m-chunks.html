Configure MediaRecorder Timeslice for WebM Chunks

This guide explains how to configure the MediaRecorder API to emit chunked WebM data packets at fixed time intervals using the timeslice parameter. You will learn how to initialize the recorder with the appropriate WebM MIME types, trigger periodic dataavailable events, handle the resulting Blob chunks, and manage stream data for real-time processing or uploading.

Understanding the Timeslice Parameter

By default, the MediaRecorder interface generates a single large Blob when recording stops. However, passing a timeslice argument (measured in milliseconds) to the MediaRecorder.start() method forces the recorder to slice the recording into separate chunks.

Whenever the specified interval elapses, or when the recording ends, the recorder fires a dataavailable event containing a WebM-encoded Blob for that duration.

Step-by-Step Implementation

1. Capture the Media Stream

First, obtain a media stream from the user's camera, microphone, or display surface using navigator.mediaDevices.getUserMedia().

const stream = await navigator.mediaDevices.getUserMedia({
  video: true,
  audio: true
});

2. Instantiate MediaRecorder with WebM MIME Type

Check for supported WebM container formats and codecs, then initialize the MediaRecorder instance.

const options = {
  mimeType: 'video/webm; codecs=vp8,opus'
};

// Fallback to default WebM container if specific codecs are not supported
const mimeType = MediaRecorder.isTypeSupported(options.mimeType)
  ? options.mimeType
  : 'video/webm';

const mediaRecorder = new MediaRecorder(stream, { mimeType });

3. Handle the Emitted Data Packets

Attach an event listener to the dataavailable event. Every time the interval defined by timeslice expires, this event provides access to the chunked packet via event.data.

mediaRecorder.ondataavailable = (event) => {
  if (event.data && event.data.size > 0) {
    const chunk = event.data; // Blob containing the WebM packet
    processWebMChunk(chunk);
  }
};

function processWebMChunk(blob) {
  // Transmit over WebSocket, push to an array, or upload via Fetch API
  console.log(`Received WebM chunk: ${blob.size} bytes`);
}

4. Start Recording with a Timeslice

Pass the desired millisecond interval to mediaRecorder.start(timeslice). For example, to emit data packets every 1000 milliseconds (1 second):

const timesliceInterval = 1000; // Emit chunk every 1 second
mediaRecorder.start(timesliceInterval);

To stop recording and receive the final remaining packet:

mediaRecorder.stop();

Complete Example

async function startWebMStreaming() {
  try {
    const stream = await navigator.mediaDevices.getUserMedia({ video: true, audio: true });
    
    const mediaRecorder = new MediaRecorder(stream, {
      mimeType: 'video/webm; codecs=vp8,opus'
    });

    mediaRecorder.ondataavailable = (event) => {
      if (event.data.size > 0) {
        // Send chunk to server or append to buffer
        console.log('Emitted chunk size:', event.data.size);
      }
    };

    // Emit a chunk every 500ms
    mediaRecorder.start(500);

    // Stop recording after 5 seconds
    setTimeout(() => {
      mediaRecorder.stop();
      stream.getTracks().forEach(track => track.stop());
    }, 5000);

  } catch (error) {
    console.error('Error recording stream:', error);
  }
}

Key Considerations for WebM Chunking

  • Container Headers (Initialization Segment): The very first chunk emitted contains the WebM initialization metadata (EBML header, Segment, and Track elements). Subsequent chunks contain media Clusters. If you are replaying or streaming these chunks to another destination, the receiving decoder must receive the first chunk to decode subsequent slices correctly.
  • Interval Accuracy: The timeslice duration is not strictly guaranteed to the exact millisecond. Browsers typically align chunk emission to keyframes or internal buffer limits, causing slight variations in chunk delivery timing.
  • Manual Requesting: You can manually trigger a data packet emission without stopping the recorder by invoking mediaRecorder.requestData().
