Parse WebM Containers with Libwebm Without Dependencies

This guide demonstrates how developers can integrate and use Google's libwebm C++ library to parse WebM (Matroska) container elements directly without relying on external third-party dependencies. By leveraging the built-in mkvparser subsystem and its default file reader implementation, you can read headers, track configurations, and video or audio clusters purely using standard C++ libraries.

Integrating Libwebm as a Standalone Parser

The libwebm repository includes an independent parser module located in the mkvparser directory. This module has no external runtime requirements beyond the standard C++ library.

To use it without external dependencies, add the following core source files directly to your build system (such as CMake, Make, or a custom toolchain):

  • mkvparser/mkvparser.cc
  • mkvparser/mkvreader.cc
  • mkvparser/mkvparser.h
  • mkvparser/mkvreader.h

Ensure your project compiler enables C++11 or later.

Implementing the Reader Interface

Parsing begins by reading raw bytes from a source. The libwebm parser decouples parsing logic from file I/O via the mkvparser::IMkvReader interface. For local files, libwebm provides a built-in standard I/O implementation named mkvparser::MkvReader which uses FILE* under the hood.

#include "mkvparser/mkvparser.h"
#include "mkvparser/mkvreader.h"
#include <iostream>

int main() {
    mkvparser::MkvReader reader;
    
    // Open the target WebM file using the built-in reader
    if (reader.Open("input.webm") != 0) {
        std::cerr << "Failed to open WebM file." << std::endl;
        return -1;
    }

    // Processing logic continues below...
    reader.Close();
    return 0;
}

If reading from memory buffers or custom network streams, you can subclass mkvparser::IMkvReader and implement Read() and Length() methods manually without modifying the parser.

Parsing the EBML Header

Every WebM file starts with an EBML (Extensible Binary Meta Language) header specifying document types and versions.

long long pos = 0;
mkvparser::EBMLHeader ebmlHeader;

// Parse the EBML Header
long long status = ebmlHeader.Parse(&reader, pos);
if (status < 0) {
    std::cerr << "Invalid EBML header." << std::endl;
    return -1;
}

std::cout << "DocType: " << ebmlHeader.m_docType << std::endl;
std::cout << "DocTypeVersion: " << ebmlHeader.m_docTypeVersion << std::endl;

Initializing the Segment

The bulk of a WebM file resides within the Segment container element. Initialize the segment using mkvparser::Segment::CreateInstance and load its header information:

mkvparser::Segment* segment = nullptr;
status = mkvparser::Segment::CreateInstance(&reader, pos, segment);
if (status < 0 || segment == nullptr) {
    std::cerr << "Failed to create Segment instance." << std::endl;
    return -1;
}

// Load the segment header and payload index
status = segment->Load();
if (status < 0) {
    std::cerr << "Failed to load segment content." << std::endl;
    delete segment;
    return -1;
}

Reading Track Metadata

Tracks contain metadata for individual audio, video, or subtitle streams. The Tracks element can be fetched directly from the segment instance:

const mkvparser::Tracks* tracks = segment->GetTracks();
if (tracks == nullptr) {
    std::cerr << "No tracks found." << std::endl;
    delete segment;
    return -1;
}

for (unsigned long i = 0; i < tracks->GetTracksCount(); ++i) {
    const mkvparser::Track* track = tracks->GetTrackByIndex(i);
    if (!track) continue;

    long long trackType = track->GetType();
    std::cout << "Track Number: " << track->GetNumber() << "\n";
    std::cout << "Codec ID: " << track->GetCodecId() << "\n";

    if (trackType == mkvparser::Track::kVideo) {
        const auto* videoTrack = static_cast<const mkvparser::VideoTrack*>(track);
        std::cout << "Type: Video\n";
        std::cout << "Width: " << videoTrack->GetWidth() << "\n";
        std::cout << "Height: " << videoTrack->GetHeight() << "\n";
    } else if (trackType == mkvparser::Track::kAudio) {
        const auto* audioTrack = static_cast<const mkvparser::AudioTrack*>(track);
        std::cout << "Type: Audio\n";
        std::cout << "Channels: " << audioTrack->GetChannels() << "\n";
        std::cout << "Sampling Rate: " << audioTrack->GetSamplingRate() << "\n";
    }
}

Iterating Clusters and Frames

Clusters store elementary stream payloads encapsulated inside SimpleBlock or Block elements. Iterate through clusters to access encoded media packets:

const mkvparser::Cluster* cluster = segment->GetFirst();

while (cluster != nullptr && !cluster->EOS()) {
    const mkvparser::BlockEntry* blockEntry = nullptr;
    status = cluster->GetFirst(blockEntry);

    while (status == 0 && blockEntry != nullptr && !blockEntry->EOS()) {
        const mkvparser::Block* block = blockEntry->GetBlock();
        long long trackNum = block->GetTrackNumber();
        long long time_ns = block->GetTime(cluster);
        int frameCount = block->GetFrameCount();

        for (int f = 0; f < frameCount; ++f) {
            const mkvparser::Block::Frame& frame = block->GetFrame(f);
            // frame.pos provides file offset; frame.len provides byte length
            std::cout << "Track " << trackNum 
                      << " Frame Size: " << frame.len 
                      << " Timestamp (ns): " << time_ns << std::endl;
        }

        status = cluster->GetNext(blockEntry, blockEntry);
    }

    cluster = segment->GetNext(cluster);
}

// Clean up
delete segment;

By including the mkvparser source files directly and interfacing through mkvparser::MkvReader, WebM parsing can be completely isolated inside any C++ application without requiring external runtime wrappers or additional library dependencies.
