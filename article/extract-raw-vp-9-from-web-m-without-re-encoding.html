Extract Raw VP9 from WebM Without Re-Encoding

Extracting raw VP9 bitstreams directly from a WebM container allows you to access the underlying video stream without quality loss or time-consuming re-encoding. This guide provides the exact commands using standard tools like FFmpeg and MKVToolNix to demux and dump raw VP9 bitstreams into standard elementary stream formats such as IVF.

Method 1: Using FFmpeg (Recommended)

The standard and most versatile tool for extracting the VP9 stream is FFmpeg. Because pure raw VP9 elementary streams lack synchronization metadata, they are typically wrapped in an IVF (Indeo Video Format) container, which is the standard raw bitstream container format for VP8 and VP9.

Run the following command in your terminal:

ffmpeg -i input.webm -c:v copy -an output.ivf

Breakdown of the command:

  • -i input.webm: Specifies the input WebM file.
  • -c:v copy: Instructs FFmpeg to perform a stream copy on the video track without re-encoding.
  • -an: Strips out any audio tracks (such as Opus or Vorbis) present in the container.
  • output.ivf: The destination file using the IVF container to hold the raw VP9 frames.

Method 2: Using MKVToolNix (mkvextract)

Since WebM is a subset of the Matroska format, you can also use mkvextract from the MKVToolNix package to extract the raw video track.

  1. Identify the video track ID:

    mkvmerge -i input.webm

    Look for the line describing the VP9 video track (for example, Track ID 0: video (VP9)).

  2. Extract the VP9 track:

    mkvextract input.webm tracks 0:output.ivf

    Replace 0 with the actual track ID identified in the previous step. mkvextract will write the uncompressed track payload into the specified output file without modifying the video data.
