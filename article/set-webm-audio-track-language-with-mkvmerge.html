Set WebM Audio Track Language with mkvmerge

This guide explains how to specify and modify the audio track language when muxing or remuxing WebM files using mkvmerge. By utilizing the --language command-line option alongside track identifiers and standard language codes, you can ensure that media players recognize and select the correct audio stream automatically.

The Primary Command-Line Option

The primary option for defining a track's language in mkvmerge is:

--language <TID>:<language-code>
  • <TID> (Track ID): The numerical identifier of the track you want to modify (e.g., 0, 1, 2).
  • <language-code>: An ISO 639-2 three-letter code (e.g., eng, fre, ger, jpn) or a BCP 47 / RFC 5646 language tag (e.g., en-US, es-ES).

Step-by-Step Usage

1. Identify the Track ID

Before setting the language, determine the ID of the audio track within your source file using the identification flag:

mkvmerge -i input.webm

Example Output:

File 'input.webm': container: WebM
Track ID 0: video (VP9)
Track ID 1: audio (Opus)

In this example, the audio track ID is 1.

2. Set the Language Flag

Run mkvmerge with the -o (output) option and the --language flag targeting the audio track ID:

mkvmerge -o output.webm --language 1:eng input.webm

Common Use Cases

Setting Language When Merging Separate Video and Audio Files

When combining a standalone WebM video file and a separate audio file (e.g., Opus or Vorbis), the track ID references the position in the specific input file it follows.

mkvmerge -o final.webm video.webm --language 0:spa audio.opus

Setting Multiple Audio Track Languages

If you are packaging a WebM container with multiple audio streams, apply the --language flag for each track:

mkvmerge -o multilingual.webm video.webm --language 0:eng english.opus --language 0:jpn japanese.opus

Setting Default and Forced Flags

To specify an audio track as the default or forced track alongside the language tag, combine --language with --default-track-flag or --forced-display-flag:

mkvmerge -o output.webm --language 1:eng --default-track-flag 1:yes input.webm

WebM Requirements and Considerations

  • Supported Audio Codecs: WebM only supports Opus and Vorbis audio. mkvmerge will automatically enforce WebM-compliant muxing when the output filename ends with .webm.
  • Language Standards: MKVToolNix version 40.0.0 and newer defaults to IETF BCP 47 language tags while maintaining backward compatibility with standard ISO 639-2 codes.
