Extract Chapters and Cue Points from WebM Video

WebM files store navigation data such as chapters and cue points within their container metadata, which is based on the Matroska (EBML) structure. This guide explains how to extract individual chapter markers, timestamps, and cue points directly from a WebM file into structured formats like JSON, XML, or plain text using industry-standard tools including FFmpeg, FFprobe, and MKVToolNix.

Method 1: Using FFprobe (JSON or Plain Text)

FFprobe is the most versatile tool for extracting structured metadata from multimedia containers without re-encoding.

To extract chapters and their start/end timestamps directly into a JSON file:

ffprobe -v quiet -print_format json -show_chapters input.webm > chapters.json

The output JSON will contain an array of chapter objects with id, time_base, start_time, end_time, and associated tag titles.

To extract the metadata in FFmpeg's native metadata format:

ffmpeg -i input.webm -f ffmetadata metadata.txt

This creates a text file containing header metadata along with sequential [CHAPTER] blocks specifying timestamps and titles.

Method 2: Using MKVToolNix (mkvextract)

Because WebM is a restricted subset of the Matroska format, MKVToolNix utilities can read and extract WebM chapter and cue data natively.

To extract chapters in Matroska XML format:

mkvextract chapters input.webm > chapters.xml

To extract chapters as a simple OGM-style text file:

mkvextract chapters input.webm -s > chapters.txt

Method 3: Extracting Cue Points with mkvinfo

Cue points (WebM index points used for seeking) are separate from chapter markers. You can inspect and parse individual cue entries using mkvinfo:

mkvinfo input.webm --heads

To isolate cue elements specifically:

mkvinfo input.webm | grep -A 4 "CueTrackPositions"

This outputs the exact cue times, cue cluster positions, and track references used by video players to navigate the stream.
