Spherical Video Projection Metadata in WebM

This article provides an overview of the metadata structures within the WebM container used to signal and configure spherical (360-degree) video projections. Because WebM is a subset of the Matroska (MKV) format built on Extensible Binary Meta Language (EBML), it utilizes specific EBML elements within the video track definition to inform media players and decoders how to map flat video frames onto a 3D sphere or mesh.

The EBML Hierarchy

Spherical video signaling in WebM is nested inside the standard track definition structure. The hierarchy appears as follows:

Segment (0x18538067)
└── Tracks (0x1654AE6B)
    └── TrackEntry (0xAE)
        └── Video (0xE0)
            └── Projection (0x7670)

The presence of the Projection element directly signals that the video track contains projection geometry metadata, enabling spatial rendering in compliant players.

The Projection Master Element

The Projection master element (EBML ID: 0x7670) contains several child elements that define the type of projection, coordinate orientation, and any custom mapping data:

  • ProjectionType (EBML ID: 0x7671): An unsigned integer defining the mathematical projection method used to encode the video. The standardized values are:

    • 0: Rectangular (standard flat video, default)
    • 1: Equirectangular (standard 360-degree latitude/longitude projection)
    • 2: Cubemap (surfaces of a cube mapped into the frame)
    • 3: Mesh (custom 3D geometry defined by vertex data)

  • ProjectionData (EBML ID: 0x7672): A binary payload containing projection-specific configuration. For example, when ProjectionType is set to Mesh (3), this field holds the raw vertex, coordinate, and polygon data describing the projection shape. For cubemap projections, it may define layout and padding information.

  • ProjectionPoseYaw (EBML ID: 0x7673): A float value representing the yaw (rotation around the vertical axis) in degrees, ranging from -180.0 to 180.0. It defines the default horizontal viewing offset.

  • ProjectionPosePitch (EBML ID: 0x7674): A float value representing the pitch (rotation around the lateral axis) in degrees, ranging from -90.0 to 90.0. It defines the default vertical viewing offset.

  • ProjectionPoseRoll (EBML ID: 0x7675): A float value representing the roll (rotation around the longitudinal axis) in degrees, ranging from -180.0 to 180.0. It corrects for camera tilt.

Parser and Player Behavior

When a WebM parser processes a track, it scans the Video element for the 0x7670 identifier. If the Projection element is missing, players treat the video as standard 2D flat video. When present, the player uses ProjectionType to initialize a 3D rendering pipeline (such as WebGL or an internal spherical shader), aligns the initial camera orientation using the ProjectionPose values, and maps the decoded video stream continuously onto the designated geometry.
