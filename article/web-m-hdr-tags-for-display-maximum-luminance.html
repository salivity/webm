WebM HDR Tags for Display Maximum Luminance

High Dynamic Range (HDR) video in WebM containers relies on standardized metadata to inform playback hardware and displays how to accurately tone-map luminance levels. This guide outlines the specific Matroska/WebM container elements responsible for signaling maximum luminance values for mastering displays and content peak brightness.

The Primary Display Luminance Tag: LuminanceMax

In a WebM container, the maximum luminance of the mastering display is signaled using the LuminanceMax element.

This tag is nested within the video track's color hierarchy:

  • Segment (0x18538067)
    • Tracks (0x1654AE6B)
      • TrackEntry (0xAE)
        • Video (0xE0)
          • Colour (0x55B0)
            • MasteringMetadata (0x55D0)
              • LuminanceMax (0x55D9)

Specifications for LuminanceMax:

  • Data Type: Float
  • Units: Candelas per square meter (\(\text{cd/m}^2\), commonly referred to as nits)
  • Function: Specifies the maximum luminance capability of the mastering monitor used during content grading (e.g., 1000.0 for a 1,000-nit display or 4000.0 for a 4,000-nit display).

Related HDR Luminance Elements in WebM

For complete and standard-compliant HDR signaling (such as HDR10), LuminanceMax works alongside several complementary elements within the same container block:

1. LuminanceMin (0x55DA)

  • Location: Inside MasteringMetadata
  • Data Type: Float (\(\text{cd/m}^2\))
  • Function: Specifies the minimum black level capability of the mastering display (e.g., 0.005 or 0.0001 nits).

2. MaxCLL (0x55E9) — Maximum Content Light Level

  • Location: Directly inside Colour (0x55B0)
  • Data Type: Unsigned Integer (nits)
  • Function: Denotes the maximum luminance of the brightest individual pixel across the entire video stream.

3. MaxFALL (0x55EA) — Maximum Frame-Average Light Level

  • Location: Directly inside Colour (0x55B0)
  • Data Type: Unsigned Integer (nits)
  • Function: Defines the highest average luminance across any single frame in the video stream.

Together, LuminanceMax and MaxCLL give decoders and displays the static HDR metadata necessary to optimize brightness mapping without clipping highlights or crushing shadow details.
