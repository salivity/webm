Tools to Edit WebM 3D Stereoscopic Metadata

WebM containers utilize Matroska-based EBML elements to store 3D stereoscopic metadata, specifically using the StereoMode tag within the video track header to dictate how left and right eye streams are arranged. This article outlines the primary software tools available—including FFmpeg, MKVToolNix, and Google’s libwebm—that allow you to read, inject, or convert these 3D stereoscopic metadata tags efficiently, often without requiring a full re-encode of the underlying video stream.

FFmpeg

FFmpeg is one of the most flexible command-line utilities for managing WebM metadata. It supports reading and writing standard stereoscopic arrangements such as side-by-side, top-bottom, and frame-sequential formats.

To convert or apply a 3D tag to an existing WebM stream without re-encoding the video, use the -stereo_mode parameter in conjunction with stream copying:

ffmpeg -i input.webm -c copy -stereo_mode left_right output.webm

Supported values for -stereo_mode include mono, left_right, bottom_top, top_bottom, and right_left. When transcoding video into WebM (using VP8, VP9, or AV1), applying this flag ensures the appropriate EBML StereoMode value is written into the container header.

MKVToolNix (mkvpropedit)

Because WebM is a subset of the Matroska (MKV) format, the MKVToolNix suite can directly parse and modify WebM files. The mkvpropedit tool is particularly useful because it modifies container headers in place without requiring the file to be remuxed or rewritten entirely.

To change the 3D stereoscopic metadata using mkvpropedit:

mkvpropedit video.webm --edit track:v1 --set stereo-mode=1

In this syntax, stereo-mode takes integer values according to the Matroska specification (for example, 1 for side-by-side left eye first, 2 for top-bottom right eye first, and 3 for top-bottom left eye first).

libwebm (webmmux)

Google provides the official libwebm library, which contains reference command-line tools for authoring and inspecting WebM files. Among these, webmmux is designed specifically to package VP8/VP9 and Vorbis/Opus elementary streams into a WebM container while setting container-specific properties.

When authoring or repackaging a stream, webmmux accepts the -stereo_mode argument to define the 3D layout:

webmmux -v video_track.ivf -stereo_mode 1 -o output.webm

Additionally, the webm_info tool within the same suite can be used to inspect an existing WebM file and verify whether the StereoMode tag is properly recognized by WebM-compliant parsers.

Python EBML Libraries (ebmlite / python-ebml)

For automated or programmatic batch processing, custom Python scripts using EBML parsing libraries such as ebmlite or python-ebml allow direct manipulation of container elements. These libraries load the WebM binary schema, locate Element ID 0x53B8 (StereoMode), and allow you to update or inject the integer representing the 3D configuration directly in the file's header.
